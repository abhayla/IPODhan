DEPLOYMENT
==========

1. Environment Variables Required:
   ADMIN_AUTH_TOKEN=your-secure-token
   ADMIN_PANEL_ENABLED=true
   REDIS_HOST=localhost
   REDIS_PORT=6379
   REDIS_PASSWORD=optional

2. Build & Deploy:
   cd web
   npm install
   npm run build
   npm start

3. Verify:
   curl -X GET http://localhost:3000/api/admin/cache/clear \
     -H "Authorization: Bearer YOUR_TOKEN"

USAGE
=====

For Admins:
1. Login to admin panel
2. Go to Settings > Cache Management
3. View statistics
4. Click appropriate clear button
5. Confirm operation
6. Wait for success notification

For Developers:
API Endpoint: POST /api/admin/cache/clear
Body: { "pattern": "ipo:*" } OR { "clearAll": true }
Auth: Bearer token required
