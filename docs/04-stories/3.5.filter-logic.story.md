## Story
**As a** user browsing the IPO dashboard,
**I want** to filter IPOs by status, category, and sector using an intuitive filter UI,
**so that** I can quickly find IPOs that match my investment criteria and share filtered views with others via bookmarkable URLs.

## Acceptance Criteria
1. Filter bar component created with status, category, and sector filters
2. Status filter supports ALL, UPCOMING, OPEN, CLOSED, LISTED options
3. Category filter supports ALL, MAINBOARD, SME, RIGHTS, NCD options
4. Sector filter is a searchable dropdown populated from available sectors
5. Filter selections sync to URL query params (?status=OPEN&category=MAINBOARD&sector=Technology)
6. Dashboard updates IPO list when filters change (fetches new data from API)
7. Clear filters button resets all filters to defaults (status=OPEN, category=ALL, sector=ALL)
8. Filter state persists across page navigation and browser refresh (via URL params)
9. Responsive filter UI (collapsible on mobile, always visible on desktop)
10. Filter interactions update URL without full page reload (client-side navigation)

### Frontend Architecture
**Source:** [docs/architecture/frontend-architecture.md]

**State Management Architecture:**

**URL State (Shareable, Bookmarkable):**
- Filter params: `?status=OPEN&category=MAINBOARD&sector=Technology`
- Pagination: `?page=2` (reset to 1 when filters change)
- View preference: `?view=grid` or `?view=list`
- Combined URL: `?status=OPEN&category=MAINBOARD&sector=Technology&page=1&view=grid`

**No React Context Needed:**
This story uses URL params exclusively for filter state (per Epic 3 decision). React Context is NOT used for filters to ensure shareable/bookmarkable URLs.

**Client Component Pattern:**
```typescript
// Client Component (components/dashboard/FilterBar.tsx)
'use client';

import { useRouter, useSearchParams } from 'next/navigation';

export function FilterBar() {
  const router = useRouter();
  const searchParams = useSearchParams();

  const status = searchParams.get('status') || 'OPEN';
  const category = searchParams.get('category') || 'ALL';
  const sector = searchParams.get('sector') || 'ALL';

  const updateFilter = (key: string, value: string) => {
    const params = new URLSearchParams(searchParams);
    if (value === 'ALL' || !value) {
      params.delete(key);
    } else {
      params.set(key, value);
    }
    params.set('page', '1'); // Reset pagination when filters change
    router.push(`/dashboard?${params.toString()}`);
  };

  return (
    <div className="flex gap-4">
      <StatusFilter value={status} onChange={(v) => updateFilter('status', v)} />
      <CategoryFilter value={category} onChange={(v) => updateFilter('category', v)} />
      <SectorFilter value={sector} onChange={(v) => updateFilter('sector', v)} />
      <ClearFiltersButton onClick={clearFilters} />
    </div>
  );
}
```

**Server Component Pattern (Dashboard Page):**
```typescript
// Server Component (app/dashboard/page.tsx)
export default async function DashboardPage({ searchParams }) {
  const page = searchParams.page ? parseInt(searchParams.page) : 1;
  const view = searchParams.view || 'grid';
  const status = searchParams.status || 'OPEN';
  const category = searchParams.category || undefined;
  const sector = searchParams.sector || undefined;

  try {
    const { data: ipos, pagination } = await apiClient.getIPOs({
      status,
      category,
      sector,
      page,
      limit: 12
    });

    return (
      <>
        <FilterBar />
        <DashboardContent
          initialIPOs={ipos}
          initialPagination={pagination}
          initialView={view}
        />
      </>
    );
  } catch (error) {
    throw error;
  }
}
```

### Filter Logic Flow

**User Interaction Flow:**
1. User opens dashboard → Reads filters from URL params → Displays filtered IPOs
2. User changes status filter → Updates URL param → Dashboard refetches data
3. User applies multiple filters → Combines URL params → Backend filters data
4. User clicks clear filters → Resets URL to defaults → Shows all OPEN IPOs
5. User bookmarks URL → Returns later → Same filtered view restored

**URL Param Handling Logic:**
```typescript
// Reading URL params (Server Component)
const status = searchParams.status || 'OPEN';
const category = searchParams.category; // undefined if not set
const sector = searchParams.sector; // undefined if not set

// Updating URL params (Client Component)
const updateFilter = (key: string, value: string) => {
  const params = new URLSearchParams(searchParams);

  // Handle 'ALL' option (remove param)
  if (value === 'ALL' || !value) {
    params.delete(key);
    if (key === 'status') {
      params.set('status', 'OPEN'); // Keep status=OPEN as default
    }
  } else {
    params.set(key, value);
  }

  // Reset pagination
  params.set('page', '1');

  // Navigate with updated params
  router.push(`/dashboard?${params.toString()}`);
};
```

**Default Filter Values:**
- Status: OPEN (show current IPOs)
- Category: ALL (undefined in URL, show all categories)
- Sector: ALL (undefined in URL, show all sectors)
- Page: 1 (reset when filters change)

**Filter Combinations:**
- Single filter: `?status=OPEN`
- Multiple filters: `?status=OPEN&category=MAINBOARD&sector=Technology`
- With pagination: `?status=OPEN&category=MAINBOARD&page=2`
- With view toggle: `?status=OPEN&category=MAINBOARD&view=list`

### Sector Filter Implementation Details

**GET /api/sectors Endpoint:**

**File:** `web/app/api/sectors/route.ts`

**Implementation:**
```typescript
import { NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { ipos } from '@/lib/db/schema';
import { sql } from 'drizzle-orm';
import { redis } from '@/lib/redis';

export async function GET() {
  try {
    // Check cache first
    const cached = await redis.get('sectors');
    if (cached) {
      return NextResponse.json({ sectors: JSON.parse(cached) });
    }

    // Query distinct sectors
    const result = await db
      .selectDistinct({ sector: ipos.sector })
      .from(ipos)
      .where(sql`${ipos.sector} IS NOT NULL AND ${ipos.sector} != ''`)
      .orderBy(ipos.sector);

    const sectors = result.map(row => row.sector);

    // Cache for 1 hour
    await redis.setex('sectors', 3600, JSON.stringify(sectors));

    return NextResponse.json({ sectors });
  } catch (error) {
    console.error('Failed to fetch sectors:', error);
    return NextResponse.json(
      { error: { code: 'INTERNAL_ERROR', message: 'Failed to fetch sectors' } },
      { status: 500 }
    );
  }
}
```

**Sector Filter Client Component:**

**File:** `web/components/filters/SectorFilter.tsx`

**Implementation:**
```typescript
'use client';

import { useState, useEffect } from 'react';
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';

interface SectorFilterProps {
  value: string;
  onChange: (value: string) => void;
}

export function SectorFilter({ value, onChange }: SectorFilterProps) {
  const [sectors, setSectors] = useState<string[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    fetch('/api/sectors')
      .then(res => res.json())
      .then(data => {
        setSectors(data.sectors);
        setIsLoading(false);
      })
      .catch(error => {
        console.error('Failed to fetch sectors:', error);
        setIsLoading(false);
      });
  }, []);

  return (
    <Select value={value} onValueChange={onChange} disabled={isLoading}>
      <SelectTrigger className="w-[180px]" aria-label="Filter by sector">
        <SelectValue placeholder={isLoading ? "Loading..." : "All Sectors"} />
      </SelectTrigger>
      <SelectContent>
        <SelectItem value="ALL">All Sectors</SelectItem>
        {sectors.map(sector => (
          <SelectItem key={sector} value={sector}>
            {sector}
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  );
}
```
