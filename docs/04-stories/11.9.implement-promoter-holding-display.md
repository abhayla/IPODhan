## Story Overview

### Business Problem

IPODhan currently has **0% implementation** of promoter holding information - a critical gap compared to competitors like Chittorgarh.com. Investors need to see promoter shareholding patterns (pre-IPO vs post-IPO) to understand:
- **Ownership Dilution**: How much control promoters are giving up
- **Promoter Commitment**: Higher post-IPO holding indicates confidence
- **Investment Risk**: Significant dilution may signal cash-out intentions

**Current State:**
- No promoter holding data displayed anywhere on IPO detail page
- Database schema lacks fields for pre/post IPO promoter percentages
- Users must manually check DRHP documents for this critical information

**Competitive Gap:**
- Chittorgarh shows: "Promoter Holding Pre Issue: 77.00%, Post Issue: 62%"
- IPODhan shows: Nothing (0% coverage)

### User Story

**As an** investor researching an IPO

**I want to** see promoter shareholding percentages before and after the IPO

**So that** I can assess promoter commitment and ownership dilution as part of my investment decision

### React Component Implementation

**File:** `web/components/ipo-detail/PromoterHoldingSection.tsx`

```typescript
import React from 'react';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { InfoCircledIcon } from '@radix-ui/react-icons';

interface PromoterHoldingSectionProps {
  promoterHoldingPreIssue?: number | null;
  promoterHoldingPostIssue?: number | null;
}

export function PromoterHoldingSection({
  promoterHoldingPreIssue,
  promoterHoldingPostIssue
}: PromoterHoldingSectionProps) {
  // Calculate equity dilution
  const equityDilution =
    promoterHoldingPreIssue !== null &&
    promoterHoldingPreIssue !== undefined &&
    promoterHoldingPostIssue !== null &&
    promoterHoldingPostIssue !== undefined
      ? (promoterHoldingPreIssue - promoterHoldingPostIssue).toFixed(2)
      : null;

  // Determine dilution color
  const getDilutionColor = (dilution: number): string => {
    if (dilution < 10) return 'text-green-600';
    if (dilution >= 10 && dilution <= 20) return 'text-yellow-600';
    return 'text-red-600';
  };

  // Empty state: No data available
  if (
    (promoterHoldingPreIssue === null || promoterHoldingPreIssue === undefined) &&
    (promoterHoldingPostIssue === null || promoterHoldingPostIssue === undefined)
  ) {
    return (
      <Card>
        <CardHeader>
          <CardTitle>Promoter Holding Pattern</CardTitle>
        </CardHeader>
        <CardContent>
          <div className="flex items-center gap-2 text-muted-foreground">
            <InfoCircledIcon className="h-4 w-4" />
            <p className="text-sm">Promoter holding data not available</p>
          </div>
        </CardContent>
      </Card>
    );
  }

  return (
    <Card>
      <CardHeader>
        <CardTitle>Promoter Holding Pattern</CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        {/* Pre-Issue Holding */}
        {promoterHoldingPreIssue !== null && promoterHoldingPreIssue !== undefined ? (
          <div className="flex justify-between items-center">
            <span className="text-sm font-medium">Promoter Holding Pre Issue:</span>
            <span className="text-sm font-semibold">{promoterHoldingPreIssue.toFixed(2)}%</span>
          </div>
        ) : (
          <div className="flex justify-between items-center">
            <span className="text-sm font-medium">Promoter Holding Pre Issue:</span>
            <span className="text-sm text-muted-foreground">Not available</span>
          </div>
        )}

        {/* Post-Issue Holding */}
        {promoterHoldingPostIssue !== null && promoterHoldingPostIssue !== undefined ? (
          <div className="flex justify-between items-center">
            <span className="text-sm font-medium">Promoter Holding Post Issue:</span>
            <span className="text-sm font-semibold">{promoterHoldingPostIssue.toFixed(2)}%</span>
          </div>
        ) : (
          <div className="flex justify-between items-center">
            <span className="text-sm font-medium">Promoter Holding Post Issue:</span>
            <span className="text-sm text-muted-foreground">
              {promoterHoldingPreIssue !== null ? 'Post-IPO data not available yet' : 'Not available'}
            </span>
          </div>
        )}

        {/* Equity Dilution */}
        {equityDilution !== null && (
          <div className="flex justify-between items-center pt-2 border-t">
            <span className="text-sm font-medium">Equity Dilution:</span>
            <span className={`text-sm font-bold ${getDilutionColor(parseFloat(equityDilution))}`}>
              {equityDilution}%
            </span>
          </div>
        )}

        {/* Helper Text */}
        <div className="mt-4 p-3 bg-muted rounded-md">
          <p className="text-xs text-muted-foreground">
            Equity dilution is calculated as the difference between pre-issue and post-issue promoter holding.
            Lower dilution indicates higher promoter commitment.
          </p>
        </div>
      </CardContent>
    </Card>
  );
}
```

The existing `FinancialDataRepository` will automatically include the new fields thanks to Drizzle type inference:

```typescript
// web/lib/repositories/financial-data-repository.ts
export class FinancialDataRepository extends BaseRepository {
  async findByIpoId(ipoId: string): Promise<FinancialData | null> {
    return this.getFromCache(
      getFinancialDataByIpoIdKey(ipoId),
      async () => {
        const result = await this.db.select().from(financialData)
          .where(eq(financialData.ipoId, ipoId));
        return result[0] || null;
      },
      CacheTTL.STATIC_DATA // 24 hours
    );
  }
}

// - promoterHoldingPostIssue

// Future enhancement: scraper/src/parsers/promoter-holding-parser.ts
export function parsePromoterHolding(drhpText: string) {
  // RegEx patterns to extract:
  // - "Promoter holding pre-issue: 77.00%"
  // - "Post-issue promoter shareholding: 62.00%"

  const preIssueMatch = drhpText.match(/promoter.*pre.?issue[:\s]+(\d+\.\d+)%/i);
  const postIssueMatch = drhpText.match(/promoter.*post.?issue[:\s]+(\d+\.\d+)%/i);

  return {
    promoterHoldingPreIssue: preIssueMatch ? parseFloat(preIssueMatch[1]) : null,
    promoterHoldingPostIssue: postIssueMatch ? parseFloat(postIssueMatch[1]) : null
  };
}
```
