# Story 12.4: Add Missing Core IPO Details (Price, Issue Size, Registrar, Documents)

## Status
**Ready** - High Priority (P1)

## Story
**As a** IPO investor,
**I want** complete IPO details including price band, issue size, registrar information, and documents,
**so that** I have all information needed to make investment decisions and check allotment status.

## Problem Statement
Cool Caps Industries Limited is missing critical IPO information that is available on NSE:

**Missing on IPODhan**:
- Price Band: N/A (NSE: ₹36-38)
- Issue Size: ₹0 Crores / null (NSE: 30.6 lakh shares = ~₹11.63 Cr)
- Registrar: N/A (NSE: Link Intime India Pvt Ltd with full contact details)
- Lead Manager: N/A (NSE: Holani Consultants Private Limited)
- Documents: Not visible (NSE: Prospectus, Forms, Ratios, Live Parameters - all available as ZIP downloads)

**Impact**: Users cannot:
- Calculate investment amounts (no price band)
- Assess IPO scale (no issue size)
- Check allotment status (no registrar contact)
- Download IPO documents (prospectus missing)

## Acceptance Criteria
1. Cool Caps must show price band: ₹36 - ₹38
2. Cool Caps must show issue size: ₹11.63 Crores (calculated from 30.6L shares × ₹38)
3. Cool Caps must show registrar: Link Intime India Pvt Ltd with contact details
4. Cool Caps must show lead manager: Holani Consultants Private Limited
5. Cool Caps must have document links (Prospectus, Forms, Ratios, Live Parameters)
6. Documents must be displayed as clickable links (download from NSE, not store files)
7. All IPOs should have these fields populated by scraper
8. UI must handle NULL values gracefully (show "TBA" or "N/A")
9. Issue size must be calculated automatically: shares × upper_price
10. Database must have fields for all missing data
