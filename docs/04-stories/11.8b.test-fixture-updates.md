## Technical Approach

### Pattern 1: Simple MAINBOARD IPO
```typescript
// OLD
const mockIPO = {
  category: 'MAINBOARD',
  // ... other fields
};

// NEW
const mockIPO = {
  segment: 'MAINBOARD' as const,
  offeringType: 'IPO' as const,
  // ... other fields
};
```

### Pattern 2: Simple SME IPO
```typescript
// OLD
category: 'SME'

// NEW
segment: 'SME' as const,
offeringType: 'IPO' as const
```

### Pattern 3: Specialized Offerings
```typescript
// OLD - RIGHTS
category: 'RIGHTS'

// NEW - RIGHTS
segment: 'MAINBOARD' as const,
offeringType: 'RIGHTS' as const

// OLD - NCD
category: 'NCD'

// NEW - NCD
segment: 'MAINBOARD' as const,
offeringType: 'NCD' as const
```

### Pattern 4: Drizzle Insert Type Casting
```typescript
// OLD (causes type error)
await db.insert(ipos).values({
  segment: 'MAINBOARD', // Type 'string' not assignable
  offeringType: 'IPO',  // Type 'string' not assignable
});

// NEW (type-safe)
await db.insert(ipos).values({
  segment: 'MAINBOARD' as 'MAINBOARD' | 'SME',
  offeringType: 'IPO' as const,
});
```

### Automated Find-Replace Strategy

Use these VS Code find-replace patterns:

1. **Find:** `category: 'MAINBOARD'`
   **Replace:** `segment: 'MAINBOARD' as const,\n  offeringType: 'IPO' as const`

2. **Find:** `category: 'SME'`
   **Replace:** `segment: 'SME' as const,\n  offeringType: 'IPO' as const`

3. **Find:** `category: 'RIGHTS'`
   **Replace:** `segment: 'MAINBOARD' as const,\n  offeringType: 'RIGHTS' as const`

4. **Find:** `category: 'NCD'`
   **Replace:** `segment: 'MAINBOARD' as const,\n  offeringType: 'NCD' as const`

5. **Find:** `category: 'OFS'`
   **Replace:** `segment: 'MAINBOARD' as const,\n  offeringType: 'OFS' as const`
