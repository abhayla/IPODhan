## Story

**As a** BSE scraper system,
**I want** to correctly parse Rights Issues (RI) and Debt Issues (DPI) detail pages that use DisplayIPO.aspx format,
**so that** all 23 BSE IPOs can be validated and persisted to the database (improving success rate from 52% to 100%).

---

## Acceptance Criteria

1. **AC1: HTML Structure Inspection**
   - Inspect and document HTML structure differences between ACQDisp.aspx (OTB) and DisplayIPO.aspx (RI/DPI) pages
   - Identify CSS selectors and extraction patterns for RI/DPI page types
   - Document field mapping differences (symbol location, lead managers location, etc.)

2. **AC2: Conditional Parsing Logic**
   - Add conditional parsing logic in `bse-detail-scraper.ts` based on page type detection
   - Detect page type from URL pattern: ACQDisp.aspx vs DisplayIPO.aspx
   - Route to appropriate parsing function based on page type

3. **AC3: Symbol Field Extraction**
   - Extract `symbol` field correctly from RI/DPI detail pages
   - Handle cases where symbol may not exist on DisplayIPO.aspx pages
   - Make symbol optional for RIGHTS and NCD categories in validation

4. **AC4: Lead Managers Field Extraction**
   - Extract `leadManagers` field correctly from RI/DPI detail pages
   - Handle cases where lead managers may not exist on DisplayIPO.aspx pages
   - Make leadManagers optional for RIGHTS and NCD categories in validation

5. **AC5: Validation Success for Failed IPOs**
   - All 11 previously-failed IPOs (8 Rights + 3 Debt) must validate successfully
   - Validation schema updated to allow optional fields for RIGHTS/NCD categories
   - Failed IPOs list verified: SMC Global Securities, Indel Money, Chemmanur Credits, SUNSHIELD CHEMICALS, WARDWIZARD INNOVATIONS, 3I INFOTECH, HEALTHY LIFE AGRITEC, ASHNISHA INDUSTRIES, STAR HOUSING FINANCE, SURAJ INDUSTRIES, CAPITAL TRUST

6. **AC6: No Regressions for OTB IPOs**
   - All 12 existing OTB IPOs (using ACQDisp.aspx) continue to validate successfully
   - No changes to existing MAINBOARD/SME parsing logic
   - Validation success rate for OTB IPOs remains 100%

7. **AC7: Multi-Category Testing**
   - Test parser with all BSE IPO types: MAINBOARD, SME, RIGHTS, NCD
   - Verify each category processes correctly with appropriate field requirements
   - Integration test confirms 100% validation success rate (23/23 IPOs)

**From BSE Comprehensive Test (2025-10-18):**
- **Root Cause Identified**: Parser designed for ACQDisp.aspx (OTB pages), fails on DisplayIPO.aspx (RI/DPI pages)
- **Impact**: 48% validation failure rate (11/23 BSE IPOs)
- **Missing Fields**: symbol and leadManagers not extracted from DisplayIPO.aspx pages
- **Page URL Patterns**:
  - OTB Pages (MAINBOARD/SME): `ACQDisp.aspx` (currently working)
  - RI/DPI Pages (RIGHTS/NCD): `DisplayIPO.aspx` (currently failing)

### Data Models

**BSE Detail Page Data Interface** (Source: scraper/src/scrapers/bse-detail-scraper.ts)
```typescript
export interface BSEDetailPageData {
  symbol: string | null;              // Stock symbol (may be missing on DisplayIPO)
  openDate: string | null;            // ISO 8601 date
  closeDate: string | null;           // ISO 8601 date
  priceRangeMin: number;              // Lower price band
  priceRangeMax: number;              // Upper price band
  issueSize: number;                  // In basic units (not crores)
  lotSize: number;                    // Minimum bid quantity
  faceValue: number;                  // Face value per share
  registrar: string | null;           // Registrar name
  leadManagers: string[] | null;     // Array of lead manager names (may be missing)
  sponsorBanks: string[] | null;     // Array of sponsor bank names
  issueShares: number;                // Raw share count
}
```

### Technical Constraints

**Browser Scraping:**
- Use Cheerio for static HTML parsing (no JavaScript needed for BSE detail pages)
- No Puppeteer required (verified via curl testing)
- Rate limiting: 2 seconds between requests, 5 seconds after every 10 requests

**Error Handling:**
- Missing fields should return null (not throw errors)
- Parser should log warnings for missing data
- Failed validation should not crash scraper (continue processing other IPOs)

**Performance:**
- Parser must handle 23 BSE IPOs in under 2 minutes
- No performance degradation from adding conditional logic

**Database:**
- Schema supports RIGHTS and NCD categories (verified in Story 11.2)
- Validation schema must align with database constraints
