**Fields:**

- `openDate`: date
- `closeDate`: date

- `listingDate`: date nullable

- `faceValue`: integer
- `listingExchanges`: jsonb - array of 'NSE' | 'BSE'

### Drizzle ORM Patterns

**Schema Definition Example:**
```typescript
import { pgTable, uuid, varchar, timestamp } from 'drizzle-orm/pg-core';

export const ipos = pgTable('ipos', {
  id: uuid('id').primaryKey().defaultRandom(),
  companyName: varchar('company_name', { length: 255 }).notNull(),
  slug: varchar('slug', { length: 255 }).notNull().unique(),
  // ... other fields
  createdAt: timestamp('created_at').defaultNow().notNull(),
  updatedAt: timestamp('updated_at').defaultNow().notNull(),
}, (table) => ({
  statusIdx: index('idx_ipos_status').on(table.status),
  slugIdx: index('idx_ipos_slug').on(table.slug),
}));
```

**Relations Definition:**
```typescript
import { relations } from 'drizzle-orm';

export const iposRelations = relations(ipos, ({ many, one }) => ({
  subscriptions: many(subscriptions),
  gmpRecords: many(gmpRecords),
  financialData: one(financialData),
  documents: many(documents),
  listingPerformance: one(listingPerformance),
}));
```

**Zod Schema Example:**
```typescript
import { createInsertSchema, createSelectSchema } from 'drizzle-zod';

export const insertIPOSchema = createInsertSchema(ipos);
export const selectIPOSchema = createSelectSchema(ipos);
```

### Field Types Reference

**From Architecture Document (Data Models section, lines 212-800):**

- UUID: `uuid().defaultRandom()`
- Strings: `varchar(length)` or `text()`
- Numbers: `integer()`, `real()`, `numeric(precision, scale)`
- Dates: `timestamp()` or `date()`
- Enums: `varchar().notNull().$type<IPOCategory>()` or `pgEnum()`
- JSON: `jsonb()`
- Booleans: `boolean()`

### Important Indexes
**Source:** `docs/architecture.md` lines 966-972

- `idx_ipos_status` - Filter by IPO status (frequent query)
- `idx_ipos_slug` - Lookup by slug (unique, URL routing)
- `idx_ipos_company_name_trgm` - Full-text fuzzy search (pg_trgm extension)
- `idx_subscriptions_ipo_timestamp` - Latest subscription queries
- `idx_gmp_records_ipo_timestamp` - GMP history queries

**Note:** The trigram index requires PostgreSQL `pg_trgm` extension. This will be enabled in the migration (Story 2.2).
