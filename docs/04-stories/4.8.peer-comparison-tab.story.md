## Story

**As a** investor evaluating an IPO,
**I want** to compare the IPO's financial metrics against 3-5 peer companies in the same sector,
**so that** I can assess whether the IPO pricing is fair relative to industry benchmarks and make data-driven investment decisions.

## Acceptance Criteria

1. **Peer Comparison Tab in IPO Detail Page**
   - New "Peer Comparison" tab added to IPO detail page tab navigation
   - Tab appears after "Financials" tab, before "Documents" tab
   - Tab is only visible if peer company data exists for the IPO

2. **Peer Comparison Table Display**
   - Table displays IPO company + 3-5 peer companies (existing public companies in same sector for comparison, not other IPOs)
   - IPO row highlighted/differentiated from peer rows
   - Columns include: Company Name, Sector, Listed Status, P/E Ratio, EPS, Diluted EPS, RONW, NAV, PBV Ratio
   - All numeric values formatted with appropriate decimals and units
   - "N/A" or "-" displayed for null/missing values

3. **Visual Comparison Indicators**
   - IPO metrics that are better than peer average highlighted in green
   - IPO metrics that are worse than peer average highlighted in red
   - Metrics within ±10% of average shown in neutral color
   - Visual indicators (↑/↓ arrows) showing relative performance

4. **Industry Benchmark Row**
   - Additional row showing industry average for each metric
   - Calculated from peer company data
   - Clearly labeled as "Industry Average"
   - Helps investors see where IPO stands vs industry norm

5. **Responsive Design**
   - Table scrolls horizontally on mobile devices
   - Card-based view on mobile (one card per company) with:
     - Company name as card header
     - All metrics displayed vertically within card
     - Visual comparison indicators (green/red) for each metric
     - Cards ordered: IPO first, then peer companies, then industry average
     - Vertical scroll for navigating between cards
   - Full table view on tablet and desktop
   - Sticky first column (company name) on horizontal scroll

6. **Data Source Attribution**
   - Display data source and last updated timestamp
   - Show financial statement type (CONSOLIDATED vs STANDALONE)
   - Disclaimer about data accuracy and recency

7. **Empty State Handling**
   - If no peer data exists, show message: "Peer comparison data not yet available"
   - Tab is hidden if no peer data exists
   - No errors or crashes

## Dev Notes

### Database Context
[Source: screen-table-database-field-mapping.md#peer-company-comparison]

**Data Seeding & Maintenance:**
- Peer companies table is populated by backend data ingestion processes
- Data is sourced from financial data providers and maintained by system administrators
- If no peer companies exist for an IPO, the tab is hidden (handled gracefully)
- Empty state scenario: tab is not displayed in navigation when `peerCompanies.length === 0`
- Developers do not need to seed peer data - it comes from production data pipelines

**peer_companies Table Structure:**
- `id` (UUID) - Primary key
- `ipo_id` (UUID) - Foreign key to ipos table
- `company_name` (VARCHAR) - Peer company name
- `sector` (VARCHAR) - Peer company sector
- `is_listed` (BOOLEAN) - Whether peer is currently listed
- `pe_ratio` (NUMERIC) - Price-to-Earnings ratio
- `eps` (NUMERIC) - Earnings Per Share (Basic)
- `diluted_eps` (NUMERIC) - Diluted EPS
- `ronw` (NUMERIC) - Return on Net Worth %
- `nav` (NUMERIC) - Net Asset Value per share
- `pbv_ratio` (NUMERIC) - Price-to-Book Value ratio
- `financial_statement_type` (ENUM: CONSOLIDATED | STANDALONE)
- `data_source` (VARCHAR) - Source attribution
- `last_updated` (TIMESTAMP) - Data recency timestamp
- `created_at`, `updated_at` (TIMESTAMP) - Audit fields

**Current Status:** Table exists in database with full metrics but is COMPLETELY UNMAPPED to any UI screens. Critical for valuation assessment.

**Comparison Logic:**
```typescript
// Determine if IPO metric is better than average
function getComparisonStatus(ipoValue: number, avgValue: number, metric: string): 'better' | 'worse' | 'neutral' {
  if (!ipoValue || !avgValue) return 'neutral';

  const diff = ((ipoValue - avgValue) / avgValue) * 100;

  // For ratios where higher is better (EPS, RONW, NAV)
  const higherIsBetter = ['eps', 'dilutedEps', 'ronw', 'nav'].includes(metric);

  // For ratios where lower is better (PE, PBV in some cases)
  const lowerIsBetter = ['peRatio', 'pbvRatio'].includes(metric);

  if (Math.abs(diff) <= 10) return 'neutral'; // Within ±10%

  if (higherIsBetter) {
    return diff > 0 ? 'better' : 'worse';
  } else if (lowerIsBetter) {
    return diff < 0 ? 'better' : 'worse';
  }

  return 'neutral';
}
```
