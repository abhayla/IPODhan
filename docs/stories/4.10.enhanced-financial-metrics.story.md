# Story 4.10: Enhanced Financial Metrics (ipo_financials Migration)

## Status
Done ✅

## Story

**As a** sophisticated IPO investor,
**I want** to see comprehensive financial metrics including P/B Ratio, ROCE, industry P/E benchmark, and peer companies list,
**so that** I can conduct thorough valuation analysis and make informed investment decisions based on complete financial data.

## Acceptance Criteria

1. **Migrate from financial_data to ipo_financials Table**
   - Backend switches from `financial_data` table to `ipo_financials` table
   - All existing fields continue to work (backward compatible)
   - New fields become available: P/B Ratio, ROCE, Industry P/E, peer companies array
   - Data migration script moves existing data to new table structure

2. **Display P/B Ratio (Price-to-Book)**
   - Add P/B Ratio to Financials Tab
   - Display with 2 decimal precision
   - Label: "P/B Ratio" with tooltip explaining meaning
   - Format: "2.45" (not "2.45x")
   - Show "N/A" if data not available

3. **Display ROCE (Return on Capital Employed)**
   - Add ROCE percentage to Financials Tab
   - Display with 2 decimal precision + % sign
   - Label: "ROCE %" with tooltip
   - Format: "18.50%"
   - Color coding: >15% (green), 10-15% (yellow), <10% (red)

4. **Display Industry Average P/E**
   - Add "Industry Avg P/E" metric to Financials Tab
   - Position next to company's P/E Ratio for easy comparison
   - Show visual indicator if company P/E is higher/lower than industry
   - Tooltip explaining how to interpret vs industry average
   - Format: "22.5" with comparison arrow (↑/↓)

5. **Display Peer Companies List**
   - Add "Peer Companies" section in Financials Tab
   - Show array of peer company names from database
   - Display as clickable tags/badges (if peer IPOs exist in database)
   - Show up to 10 peer companies
   - "See all peers" link if more than 10 exist
   - Empty state: "Peer companies not yet available"

6. **Financial Year End Date Display**
   - Show financial year end date clearly
   - Format: "FY ending March 31, 2024"
   - Position at top of Financials Tab
   - Helps users understand which fiscal year the data represents

7. **Update Compare Tool**
   - Include P/B Ratio and ROCE in IPO comparison table
   - Show industry P/E for each compared IPO
   - Ensure new metrics work in side-by-side comparison

**Metric Interpretation:**

**P/B Ratio (Price-to-Book):**
```
P/B Ratio = Market Price per Share / Book Value per Share

Interpretation:
- < 1.0: Stock trading below book value (potentially undervalued)
- 1.0-3.0: Normal range for most industries
- > 3.0: Premium valuation or growth expectations

Color coding:
- Green: < 2.0 (attractive)
- Yellow: 2.0-4.0 (fair)
- Red: > 4.0 (expensive)
```

**ROCE (Return on Capital Employed):**
```
ROCE = EBIT / Capital Employed × 100

Interpretation:
- > 15%: Excellent capital efficiency
- 10-15%: Good performance
- < 10%: Poor capital usage

Color coding:
- Green: > 15%
- Yellow: 10-15%
- Red: < 10%
```

**Industry P/E Comparison:**
```
If Company P/E < Industry P/E → Potentially undervalued ↓
If Company P/E > Industry P/E → Potentially overvalued ↑

Example:
Company P/E: 18.5
Industry Avg: 22.3
Difference: -17% (Below industry → Attractive)
```

### Repository Pattern Context
[Source: CLAUDE.md#repository-pattern-with-caching]

**Repository Updates:**

```typescript
// web/lib/repositories/financial-repository.ts
import { BaseRepository } from './base-repository';
import * as schema from '@ipodhan/shared/db/schema';

export class FinancialRepository extends BaseRepository {
  async findByIPOId(ipoId: string): Promise<IPOFinancials | null> {
    const cacheKey = `financial:ipo:${ipoId}`;
    return this.getFromCache(cacheKey, async () => {
      const result = await this.db
        .select()
        .from(schema.ipoFinancials)  // Changed from schema.financialData
        .where(eq(schema.ipoFinancials.ipoId, ipoId))
        .limit(1);
      return result[0] || null;
    }, 1800); // 30-min TTL
  }
}
```
