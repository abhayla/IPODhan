## Status
**Done**

## Story
**As a** retail investor,
**I want** to view all live, upcoming, and closed IPOs with scores,
**so that** I can track IPO opportunities and make informed investment decisions.

## Acceptance Criteria

**1. Homepage Layout & Structure:**
- Hero section with tagline "India's Smartest IPO Platform"
- Live IPO count widget displaying current count
- Today's top IPO by score highlighted
- Quick search bar for IPO lookup
- IPO tabs section with three tabs: Live IPOs, Upcoming IPOs, Closed IPOs
- Quick stats bar showing: Total IPOs this year, Average listing gain, Top performing IPO, Current GMP leader
- Tab counts dynamically updated based on IPO status

**2. IPO Card Component Design:**
- Display company name, logo (optional), and category (Mainboard/SME)
- Score prominently displayed with value (0-100), label (Strong Buy/Consider/Risky/Avoid), color coding, and trend indicator
- Key dates section: open date, close date, listing date, days left for live IPOs
- Price information: price band (low-high), lot size, minimum investment amount
- Live subscription data: retail, QIB, NII, overall subscription with last updated timestamp
- GMP data: amount, percentage, and trend indicator
- Quick action buttons: View Details, Add to Watchlist, Download Forms, Check Allotment

**3. IPO List View Implementation:**
- Filters bar with options for: Score range (70+, 50-70, 30-50, <30), Category (Mainboard, SME, Both), Sector, Issue size (<100Cr, 100-500Cr, >500Cr)
- Sort by options: Score, Closing Date, GMP, Size
- IPO cards grid with responsive layout
- Subscription status bar for live IPOs showing category-wise breakdown
- Date information contextual to tab (closing countdown for live, opening date for upcoming, listing gain for closed)
- Pagination with current page, total pages, and page navigation

**4. Individual IPO Detail Page:**
- Header section with: Company info (logo, name, industry, description), Large score display (72/100) with recommendation badge, Quick actions (Download Forms, Check Allotment, Add to Watchlist, Share IPO)
- Six detail tabs: Overview, Subscription, GMP, Financials, Analysis, Documents
- Overview tab: Key metrics (issue size, price band, lot size, min investment, face value, P/E ratio), Important dates (all IPO timeline dates), Object of issue (fresh issue, OFS, use of proceeds)
- Subscription tab: Real-time subscription data, Category-wise breakdown chart, Day-wise progression chart, Auto-refresh every 15 minutes
- GMP tab: Historical GMP chart, Current GMP with trend, Kostak rates, Expected listing price
- Financials tab: Revenue/Profit last 3 years, Key ratios (P/E, ROE, ROCE), Debt analysis, Peer comparison table
- Analysis tab: Strengths and risks, Score breakdown explanation, Editorial recommendation, Key considerations
- Documents tab: DRHP/RHP download links, Application forms, Company presentations, Exchange filings
- Registrar section: Registrar name and contact, Allotment status link, Lead managers list

**5. Search & Filter Implementation:**
- Fuzzy search with typo tolerance (0.2 fuzzy factor)
- Search fields: company name (boost: 2), symbol (boost: 1.5), sector (boost: 1)
- Prefix matching enabled for partial searches
- Filter application: score range, category, sector, date range
- Results sorted by: relevance first, then score
- Search results showing: id, company name, score, status

**6. Responsive Design Requirements:**
- Mobile breakpoint: 320px (single column grid)
- Tablet breakpoint: 768px (2 column grid)
- Desktop breakpoint: 1024px (3 column grid)
- Wide breakpoint: 1440px (4 column grid)
- Mobile optimizations: Vertical subscription bar, Sticky card actions at bottom, Horizontal scrolling filters with touch support
- Responsive IPO card grid with appropriate gaps (1.5rem)

**7. Performance Optimization:**
- Page load time target: <2 seconds
- Image optimization: lazy loading for logos and charts
- Code splitting: route-based chunks for each page
- API response caching: 5 minutes for IPO lists, 15 minutes for detail pages
- CDN delivery for static assets
- Prefetching for likely next pages

**8. SEO Implementation:**
- Dynamic meta tags per page: title, description, keywords
- Open Graph tags for social sharing
- Structured data (JSON-LD) for IPO entities
- Canonical URLs for duplicate content prevention
- XML sitemap generation with priority and frequency
- robots.txt configuration

**9. Error Handling & Loading States:**
- Loading skeletons for IPO cards and detail sections
- Error boundaries for component failures
- Retry mechanism for failed API calls (3 attempts with exponential backoff)
- User-friendly error messages with actionable guidance
- Offline detection with appropriate messaging
- 404 page for invalid IPO IDs

**10. Analytics Tracking:**
- Page view events for all routes
- Click tracking on: IPO cards, filter selections, download buttons, watchlist actions
- Conversion funnel tracking: homepage → IPO details → watchlist/download
- Performance metrics: page load time, API response time
- User behavior tracking: scroll depth, time on page, exit points

**11. API Integration:**
- GET /api/ipos with query params: status (LIVE/UPCOMING/CLOSED), category (MAINBOARD/SME), page, limit
- GET /api/ipos/:id for IPO details with embedded score
- GET /api/ipos/:id/score for detailed score breakdown
- GET /api/ipos/:id/gmp with days parameter (default: 7)
- GET /api/ipos/:id/subscription for current subscription data
- Error handling with standard error response format
- Request timeout: 10 seconds with retry logic

**12. Accessibility Compliance:**
- WCAG AA compliance level
- Keyboard navigation support for all interactive elements
- Screen reader friendly with proper ARIA labels
- Color contrast ratio minimum 4.5:1 for text
- Focus indicators visible on all focusable elements
- Alt text for all images and icons
- Semantic HTML structure with proper heading hierarchy

```typescript
interface IPO {
  id: string;
  symbol: string;
  companyName: string;
  issueSize: number;
  priceBand: { low: number; high: number; };
  lotSize: number;
  dates: { open: Date; close: Date; listing: Date; };
```

```typescript
interface IPOScore {
  id: string;

  totalScore: number;
  components: {

    subscription: number;
    sector: number;
  };
  verdict: 'APPLY' | 'CONSIDER' | 'SKIP';
  confidence: 'HIGH' | 'MEDIUM' | 'LOW';
  reasoning: string;
  calculatedAt: Date;
}
```

```typescript
interface GMPHistory {

}
```

```typescript
  };

}
```
