## Dev Notes

### Issue Context (from TEST_ISSUES.json)

**Root Cause**: Next.js 15 breaking change - searchParams is now async and must be awaited before accessing properties

**Evidence**:
```
Error: Route "/mainboard-ipo-listings" used `searchParams.year`.
       `searchParams` should be awaited before using its properties.
Error: Route "/mainboard-ipo-listings" used `searchParams.page`.
       `searchParams` should be awaited before using its properties.
Error fetching IPO listings: Error: Failed to fetch IPO listings: Bad Request
GET /api/ipos/listings?category=MAINBOARD&year=function%28%29+... 400
```

**Affected Components**:
- `/mainboard-ipo-listings`
- `/sme-ipo-listings`
- Potentially other pages using searchParams

**Impact**: HIGH - Critical pages completely broken and unusable

### Relevant Source Tree

**Primary Files to Fix**:
```
app/
├── mainboard-ipo-listings/
│   └── page.tsx              # MUST FIX - Primary affected file
├── sme-ipo-listings/
│   └── page.tsx              # MUST FIX - Primary affected file
└── [other-pages]/
    └── page.tsx              # AUDIT - May need fixes
```

**Expected Pattern** (Before - BROKEN):
```typescript
export default async function Page({ searchParams }: Props) {
  const selectedYear = searchParams.year || CURRENT_YEAR; // ❌ ERROR
  const currentPage = parseInt(searchParams.page || '1', 10); // ❌ ERROR
  // ...
}
```

**Required Pattern** (After - FIXED):
```typescript
export default async function Page({ searchParams }: Props) {
  const params = await searchParams; // ✅ ADD AWAIT
  const selectedYear = params.year || CURRENT_YEAR;
  const currentPage = parseInt(params.page || '1', 10);
  // ...
}
```

### Technical Details

**Next.js 15 Breaking Change**:
- In Next.js 15, `searchParams` prop is now a Promise
- Must be awaited before accessing any properties
- Applies to all Server Components receiving searchParams
- Affects: `page.tsx`, `layout.tsx`, `route.ts` files

**TypeScript Type Definition**:
```typescript
type Props = {
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}
```

**Common Affected Patterns**:
```typescript
// ❌ All these patterns are BROKEN in Next.js 15:
searchParams.year
searchParams.page
searchParams.category
Object.keys(searchParams)
Object.entries(searchParams)

// ✅ Correct pattern:
const params = await searchParams;
params.year
params.page
params.category
Object.keys(params)
Object.entries(params)
```

```markdown
# Next.js 15 Migration: Async searchParams

## Breaking Change
searchParams is now async in Next.js 15.

## Migration Steps
1. Find all searchParams usage: `grep -r 'searchParams\.' app/`
2. Add await: `const params = await searchParams;`
3. Update property access: Use `params.propertyName` instead
4. Update TypeScript types to Promise<...>

## Example
Before:
export default async function Page({ searchParams }: Props) {
  const year = searchParams.year;
}

After:
export default async function Page({ searchParams }: Props) {
  const params = await searchParams;
  const year = params.year;
}
```
