## Story
**As a** user visiting IPODhan,
**I want** to see a dashboard displaying current IPO listings in an organized grid layout,
**so that** I can quickly browse available IPOs, view key information at a glance, and navigate to detailed pages for IPOs that interest me.

## Acceptance Criteria
1. Dashboard page created at `/dashboard` route (app/dashboard/page.tsx)
2. Fetches IPO data using API client service (getIPOs method)
3. Displays IPO cards in responsive grid layout (1 column mobile, 2 tablet, 3 desktop)
4. Pagination controls with page navigation (prev/next, page numbers)
5. View toggle between grid and list layouts
6. Responsive design across mobile, tablet, desktop
7. SEO metadata (title, description, Open Graph tags)
8. Performance optimized (lazy loading, loading states, error boundaries)

**URL State (Shareable, Bookmarkable):**

- Filters: `?status=OPEN&category=MAINBOARD` (when added in Task 11)

**Local Component State (React useState):**
- Loading indicators (isLoading)
- Error states (error message)
- UI states (hover, focus)

**No React Context Needed:**
This story does NOT require React Context. All state is either in URL (for shareability) or local component state (for UI feedback). React Context is for global app-wide state (theme, user preferences, auth) which is not in scope for this story.

**Data Fetching Pattern:**
```typescript
// Server Component (app/dashboard/page.tsx)
export default async function DashboardPage({ searchParams }) {
  const page = searchParams.page ? parseInt(searchParams.page) : 1;
  const view = searchParams.view || 'grid';
  const status = searchParams.status || 'OPEN';

  try {
    const { data: ipos, pagination } = await apiClient.getIPOs({
      status,
      page,
      limit: 12
    });

    return (
      <DashboardContent
        initialIPOs={ipos}
        initialPagination={pagination}
        initialView={view}
      />
    );
  } catch (error) {
    // Error boundary will catch this
    throw error;
  }
}
```

**Client Component Pattern:**
```typescript
// Client Component (components/ipo/IPOGrid.tsx)
'use client';

export function IPOGrid({ ipos, view }) {
  return (
    <div className={view === 'grid' ? 'grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6' : 'flex flex-col gap-4'}>
      {ipos.map(ipo => (
        <IPOCard key={ipo.id} ipo={ipo} />
      ))}
    </div>
  );
}
```

### API Integration
**Source:** [docs/architecture/api-specification.md]

**Endpoint:** `GET /api/ipos`

**Query Parameters:**
- `status` (optional): IPOStatus enum (UPCOMING, OPEN, CLOSED, LISTED)
- `category` (optional): IPOCategory enum (MAINBOARD, SME, RIGHTS, NCD)
- `sector` (optional): string (filter by sector)
- `search` (optional): string (search company name)
- `page` (optional): number (default: 1)
- `limit` (optional): number (default: 12, max: 100)

**Response Format:**
```json
{
  "data": [
    {
      "id": "uuid",

      "slug": "example-corp",

      "rating": 4.5
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 12,
    "total": 45,
    "hasMore": true
  }
}
```

### Coding Standards
**Source:** [docs/architecture/coding-standards.md]

**Critical Rules:**
1. **API Calls:** Always use API client service, never direct fetch()
2. **Type Safety:** Import types from schema, never use 'any'
3. **Component Naming:** PascalCase (IPOGrid.tsx, Pagination.tsx)
4. **State Management:** React Context for client state, URL params for shareable state
5. **Styling:** Tailwind CSS utility classes, no inline styles
6. **Error Handling:** Always use error boundaries for route-level errors

**Naming Conventions:**
- Components: PascalCase (IPOGrid, ViewToggle, Pagination)
- Props: camelCase (initialIPOs, currentPage, onPageChange)
- Files: PascalCase for components (IPOGrid.tsx), kebab-case for routes (dashboard/page.tsx)

**Component Structure:**
```typescript
// Server Component (no 'use client')
```

### URL State Management

**URL Parameters:**
- `page` (number): Current page (default: 1)
- `view` (string): Layout view ("grid" or "list", default: "grid")
- `status` (string): IPO status filter (optional, default: "OPEN")
- `category` (string): IPO category filter (optional)

**Example URLs:**
- `/dashboard` → Default (page 1, grid view, OPEN status)
- `/dashboard?page=2` → Page 2
- `/dashboard?view=list` → List view
- `/dashboard?page=2&view=list` → Page 2, list view
- `/dashboard?status=UPCOMING` → Upcoming IPOs only

**Reading URL Params:**
```typescript
// Server Component
export default async function DashboardPage({ searchParams }) {
  const page = searchParams.page ? parseInt(searchParams.page) : 1;
  const view = searchParams.view || 'grid';
  const status = searchParams.status || 'OPEN';

  // Fetch data with params
  const { data: ipos, pagination } = await apiClient.getIPOs({
    status,
    page,
    limit: 12
  });

  return <DashboardContent ... />;
}
```

**Updating URL Params (Client Component):**
```typescript
'use client';

import { useRouter, useSearchParams } from 'next/navigation';

export function Pagination({ currentPage, totalPages }) {
  const router = useRouter();
  const searchParams = useSearchParams();

  const handlePageChange = (newPage: number) => {
    const params = new URLSearchParams(searchParams);
    params.set('page', newPage.toString());
    router.push(`/dashboard?${params.toString()}`);
  };

  return (
    <div>
      <button onClick={() => handlePageChange(currentPage - 1)}>
        Previous
      </button>
      <button onClick={() => handlePageChange(currentPage + 1)}>
        Next
      </button>
    </div>
  );
}
```
