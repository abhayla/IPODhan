# Story 4.9: Stock Symbol & ISIN Display

## Status
Done ✅

## Epic Reference
**Epic:** Epic 4 - IPO Detail Page & Information Architecture
**Story Number:** 4.9

## Story

**As a** professional investor or trader,
**I want** to see the stock symbol and ISIN code prominently displayed for each IPO,
**so that** I can easily identify securities using standard market identifiers and use them for research, trading, and portfolio tracking.

## Acceptance Criteria

1. **Stock Symbol Display in IPO Header**
   - Stock symbol (ticker) displayed prominently in IPO detail page header
   - Positioned next to or below company name
   - Clearly labeled as "Symbol" or "Ticker"
   - Shows both NSE and BSE symbols if different
   - Format: "Symbol: RELIANCE (NSE) | RELIANCE (BSE)"

2. **ISIN Display in IPO Details Section**
   - ISIN code displayed in IPO details section
   - Labeled as "ISIN"
   - Formatted with standard spacing: "ISIN: INE002A01018"
   - Copy-to-clipboard button for easy copying
   - Tooltip explaining what ISIN is

3. **Symbol Column in IPO Listing Tables**
   - Add "Symbol" column to all IPO listing tables:
     - Dashboard IPO table
     - Mainboard IPOs page table
     - SME IPOs page table
     - Historical IPOs table
     - Performance tracker tables
   - Display primary symbol (NSE if available, else BSE)
   - Mobile responsive strategy:
     - Desktop (≥768px): Show full symbol (max 20 chars)
     - Mobile (<768px): Hide symbol column (use accordion or detail view)
     - Alternative: Show first 6 chars with ellipsis (e.g., "RELIAN...")
   - Sortable column

4. **Symbol in IPO Cards**
   - Display stock symbol in IPO card component
   - Small badge or label below company name
   - Only show if symbol exists (not all upcoming IPOs have symbols yet)

5. **Search by Symbol Functionality**
   - Enable search by stock symbol in dashboard search
   - Search should match partial symbol (e.g., "REL" finds "RELIANCE")
   - Case-insensitive search
   - Prioritize exact symbol matches in results

6. **Null Symbol/ISIN Handling**
   - If symbol doesn't exist yet, show "Symbol: TBD" or hide field
   - If ISIN doesn't exist, show "ISIN: Not assigned" or hide field
   - No errors or crashes for missing data
   - Upcoming IPOs may not have symbols assigned yet

### Repository Pattern Context
[Source: CLAUDE.md#repository-pattern-with-caching]

**Repository Updates:**
```typescript
// web/lib/repositories/ipo-repository.ts
import * as schema from '@ipodhan/shared/db/schema';
import { eq } from 'drizzle-orm';

async findBySlug(slug: string): Promise<IPO | null> {
  const cacheKey = getIPOBySlugKey(slug);
  return this.getFromCache(cacheKey, async () => {
    // No join needed - symbol and isin are in ipos table
    const result = await this.db
      .select()
      .from(schema.ipos)
      .where(eq(schema.ipos.slug, slug))
      .limit(1);

    return result[0] || null;
    // Result automatically includes symbol and isin fields
  }, CacheTTL.IPO_DETAIL);
}

async findAll(filters?: IPOFilters): Promise<IPO[]> {
  const cacheKey = getIPOListKey(JSON.stringify(filters));
  return this.getFromCache(cacheKey, async () => {
    // Symbol and isin are automatically selected with all ipos fields
    const query = this.db.select().from(schema.ipos);

    // Apply filters...
    if (filters?.status) {
      query.where(eq(schema.ipos.status, filters.status));
    }

    return await query;
    // Results include symbol and isin
  }, CacheTTL.IPO_LIST);
}
```

### Copy-to-Clipboard Implementation

**Toast Library:** Use `sonner` (already in project dependencies)

```typescript
// web/components/ipo/ISINDisplay.tsx
'use client';

import { toast } from 'sonner'; // ← Use sonner toast library

const copyToClipboard = async (text: string) => {
  try {
    await navigator.clipboard.writeText(text);
    toast.success('ISIN copied to clipboard');
  } catch (error) {
    // Fallback for older browsers
    const textArea = document.createElement('textarea');
    textArea.value = text;
    document.body.appendChild(textArea);
    textArea.select();
    document.execCommand('copy');
    document.body.removeChild(textArea);
    toast.success('ISIN copied to clipboard');
  }
};
```
