## Story
**As a** user who wants to share IPO information with others,
**I want** social sharing functionality for WhatsApp, Twitter, and copy link,
**so that** I can easily spread the word about interesting IPOs.

4. Copy confirmation toast notification
5. Share tracking (analytics event)
6. Open Graph tags for rich previews
7. Twitter Card metadata
8. Share URL includes UTM parameters
9. Responsive button layout

### Key Metrics for Share Text

The share text should include these key metrics when available:
- **Company Name:** Always included (e.g., "TechCorp")
- **Rating:** Include if not null (e.g., "Rating: 4.0/5")
- **Subscription:** Include latest total subscription (e.g., "Subscription: 25x")
- **GMP:** Include latest GMP (e.g., "GMP: ₹120")
- **Issue Size:** Include if space permits (e.g., "Issue Size: ₹500 Cr")

**Example Share Texts:**
- Full metrics: "Check out TechCorp IPO (Rating: 4.0/5, Subscription: 25x, GMP: ₹120) on IPODhan"
- No rating: "Check out TechCorp IPO (Subscription: 25x, GMP: ₹120, Issue: ₹500 Cr) on IPODhan"
- Minimal data: "Check out TechCorp IPO on IPODhan"

**Twitter Character Limit:** Keep share text under 280 characters to ensure compatibility.

```typescript
// web/lib/analytics/gtag.ts
export function trackShare(platform: string, companyName: string) {
  if (typeof window !== 'undefined' && window.gtag) {
    window.gtag('event', 'share', {
      method: platform,           // 'whatsapp', 'twitter', 'copy', 'native'
      content_type: 'ipo',
      item_id: companyName,
    });
  }
}
```

**Event Parameters:**
- `method`: Share platform (whatsapp, twitter, copy, native)
- `content_type`: Always "ipo"
- `item_id`: Company name of the IPO being shared

### Next.js Metadata API

[Source: architecture/frontend-architecture.md]

Next.js 14 App Router uses the Metadata API for setting meta tags. The IPO detail page should export a `generateMetadata()` function.

**Implementation Location:**
```
web/app/ipos/[slug]/page.tsx    (UPDATE - Add generateMetadata() function)
```

**Example Implementation:**
```typescript
import type { Metadata } from 'next';

export async function generateMetadata({ params }: { params: { slug: string } }): Promise<Metadata> {
  // Fetch IPO data
  const ipo = await getIPOBySlug(params.slug);

  if (!ipo) {
    return { title: 'IPO Not Found' };
  }

  const title = `${ipo.companyName} IPO Details | IPODhan`;
  const description = `${ipo.companyName} IPO - Issue Size: ₹${ipo.issueSize} Cr${ipo.rating ? `, Rating: ${ipo.rating}/5` : ''}. Complete IPO information on IPODhan.`;
  const imageUrl = ipo.logoUrl || 'https://ipodhan.com/og-image-default.jpg';
  const url = `https://ipodhan.com/ipos/${ipo.slug}`;

  return {
    title,
    description,
    openGraph: {
      title,
      description,
      images: [imageUrl],
      url,
      type: 'website',
      siteName: 'IPODhan',
    },
    twitter: {
      card: 'summary_large_image',
      title: `${ipo.companyName} IPO | IPODhan`,
      description,
      images: [imageUrl],
      site: '@ipodhan',
    },
  };
}
```

- Same share text as Twitter for consistency
