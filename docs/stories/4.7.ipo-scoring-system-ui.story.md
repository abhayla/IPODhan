# Story 4.7: IPO Scoring System UI Implementation

## Status
Done ✅

## Story

**As a** retail investor,
**I want** to see IPODhan's AI-powered IPO scoring and verdict recommendations prominently displayed,
**so that** I can quickly assess IPO quality and make informed investment decisions based on data-driven analysis.

## Acceptance Criteria

1. **Score Badge Display**
   - Total score (0-100) displayed as a prominent badge on all IPO cards
   - Score includes visual indicator (color coding: 0-25=red, 26-50=orange, 51-75=yellow, 76-100=green)
   - Score updates reflect latest `ipo_scores.total_score` from database

2. **Verdict Display**
   - Verdict (APPLY/CONSIDER/SKIP) shown with color-coded badge
   - APPLY = green, CONSIDER = yellow, SKIP = red
   - Verdict displayed on IPO cards and detail page header

3. **Confidence Indicator**
   - Confidence level (HIGH/MEDIUM/LOW) shown with icon/badge
   - Clear visual differentiation between confidence levels
   - Tooltip explaining what confidence means

4. **IPO Detail Page Score Section**
   - Dedicated "IPODhan Score" section in IPO detail page
   - Score breakdown showing 4 component scores:
     - Fundamental Score (0-25)
     - Sentiment Score (0-25)
     - Subscription Score (0-25)
     - Sector Score (0-25)
   - Visual chart/graph showing score breakdown
   - Reasoning text displayed explaining the verdict
   - Timestamp showing when score was calculated

5. **Filter by Score**
   - Add score range filter on dashboard/listing pages
   - Filter options: 0-25, 26-50, 51-75, 76-100
   - Filter persists in URL query params

6. **Null Score Handling**
   - If `ipo_scores` record doesn't exist for an IPO, show "Score Pending" badge
   - No errors or crashes when score data is missing

### Repository Pattern Context
[Source: docs/architecture/backend-architecture.md, CLAUDE.md#repository-pattern]

**Repository Implementation Pattern:**
```typescript
// web/lib/repositories/score-repository.ts
import { BaseRepository } from './base-repository';
import * as schema from '@ipodhan/shared/db/schema';

export class ScoreRepository extends BaseRepository {
  async findByIPOId(ipoId: string): Promise<IPOScore | null> {
    const cacheKey = `score:ipo:${ipoId}`;
    return this.getFromCache(cacheKey, async () => {
      const result = await this.db
        .select()
        .from(schema.ipoScores)
        .where(eq(schema.ipoScores.ipoId, ipoId))
        .limit(1);
      return result[0] || null;
    }, 900); // 15-min TTL
  }
}
```

**Cache Keys Pattern:**
- `score:ipo:{ipoId}` - Individual IPO score
- TTL: 15 minutes (900 seconds)
