**As a** system,

## Acceptance Criteria

**1. Data Source Integration (Windows Environment):**

**NSE/BSE Official Sources:**
- **NSE IPO Page**: `https://www.nseindia.com/market-data/all-upcoming-issues-ipo`
- **BSE IPO Page**: `https://www.bseindia.com/markets/PublicIssues/IPOIssues.aspx`
- **Data extraction methods:**
  - Primary: Official APIs if available
  - Fallback: Web scraping using Puppeteer/Playwright on Windows
  - Schedule: Windows Task Scheduler jobs every 15 minutes (9:00 AM - 5:00 PM)
  - Python services running as Windows Services with NSSM wrapper

**GMP Sources:**
- **Primary**: IPOWatch.in API/Scraping
- **Secondary**: InvestorGain.com
- **Tertiary**: Chittorgarh.com
- **Update frequency**: Every 30 minutes (market hours), hourly (off-hours)

**2. Data Validation & Normalization Pipeline:**

Required validations:
- Required fields present (company_name, dates, price_band)
- Date logic (open_date < close_date < listing_date)
- Price band validation (low < high)
- Lot size is positive integer
- Issue size is positive number

Required normalizations:
- Convert dates to ISO format
- Standardize company names (remove Ltd, Limited, etc.)
- Convert all amounts to crores
- Calculate derived fields (issue_price_range)

Duplicate detection:
- Check by company name + issue dates
- Check by ISIN if available
- Merge updates vs create new records

**3. Database Schema for IPO Data:**

Extended IPO master table with fields:
- Basic info: id, isin, symbol, company_name, company_description
- Issue details: issue_type, issue_size, fresh_issue, ofs_issue
- Price information: price_band_low, price_band_high, cut_off_price, face_value, lot_size, min_investment
- Important dates: open_date, close_date, basis_of_allotment_date, initiation_of_refunds_date, credit_of_shares_date, listing_date
- Categories: ipo_category (Mainboard/SME), status (Upcoming/Open/Closed/Listed)
- Registrar info: registrar, registrar_link
- Lead managers and exchange info
- Timestamps: created_at, updated_at, data_source, last_verified_at

Financial metrics table:
- Revenue and profit data (FY1, FY2, FY3)
- Key ratios: PE, PB, ROE, ROCE, debt_to_equity
- Industry PE and peer comparison data

**4. GMP History Tracking:**

Enhanced GMP tracking with:
- GMP data: gmp_amount, gmp_percentage, expected_listing_price
- Grey market application prices: kostak_rate, subject_to_sauda
- Source tracking: source, source_url, confidence_score (1-100)
- Timestamp: recorded_at

Materialized view for current GMP aggregates:
- Average, max, min GMP across sources
- Last updated timestamp
- Refresh every 2 hours

**5. Scraper Implementation Requirements:**

- Browser automation using Playwright
- Retry mechanism (3 attempts with exponential backoff)
- 30-second timeout per request
- Handle pagination on source websites
- Error logging with Sentry integration
- Data extraction from HTML tables
- Schedule coordination to avoid rate limits

**6. Pipeline Monitoring & Error Handling:**

- Dashboard showing last successful scrape time per source
- Alert if any source fails >3 times consecutively
- Data freshness indicators (< 1 hour = green, 1-3 hours = yellow, >3 hours = red)
- Weekly report of data quality metrics
- Automated recovery procedures for common failures
- Manual override capability for critical data corrections

**Orchestrator Pattern:**
```python
# orchestrator/pipeline.py
class DataPipeline:
    def __init__(self):
        self.nse_scraper = NSEScraper()
        self.bse_scraper = BSEScraper()
        self.validator = IPODataValidator()
        self.normalizer = DataNormalizer()
        self.repository = IPODataRepository()

    def run_ipo_pipeline(self):
        """Scrape → Validate → Normalize → Store"""
        try:
            raw_nse = self.nse_scraper.scrape()
            raw_bse = self.bse_scraper.scrape()

            for raw_data in [*raw_nse, *raw_bse]:
                validated = self.validator.validate_ipo_data(raw_data)
                if validated.is_valid:
                    normalized = self.normalizer.normalize_ipo_data(validated.data)
                    self.repository.upsert_ipo_details(normalized)
                else:
                    logger.warning(f"Invalid data: {validated.errors}")
        except Exception as e:
            logger.error(f"Pipeline failed: {e}")
            sentry_sdk.capture_exception(e)

    def run_gmp_pipeline(self):
```
