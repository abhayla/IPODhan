# Story 5.8: Registrar Logos

## Status
Draft

## Story

**As a** user browsing the registrars directory,
**I want** to see registrar company logos instead of just text names,
**so that** I can quickly identify registrars visually and the directory looks more professional and user-friendly.

## Acceptance Criteria

1. **Display Logos in Registrars Directory**
   - Show `logo_url` images in registrar cards/table
   - Logo size: 80x80px (or similar square/rectangular)
   - Position: Left side of registrar name
   - Maintain aspect ratio, no distortion

2. **Display Logo in IPO Detail Page**
   - Show registrar logo next to registrar name in IPO Details section
   - Smaller size: 40x40px
   - Clickable link to registrar's website

3. **Placeholder for Missing Logos**
   - Use generic placeholder image if `logo_url` is null
   - Placeholder: Initials of registrar name in colored circle
   - Example: "Link Intime" → "LI" in circle

4. **Lazy Loading**
   - Implement lazy loading for logo images
   - Show skeleton/placeholder while loading
   - No layout shift when images load

5. **Error Handling**
   - If logo URL is broken/404, show placeholder
   - No broken image icons displayed
   - Graceful fallback to text-only display

6. **Responsive Design**
   - Desktop: Full-size logos
   - Mobile: Smaller logos to save space
   - Grid layout adjusts based on screen size

```typescript
// Generate initials from name
function getInitials(name: string): string {
  return name
    .split(' ')
    .map(word => word[0])
    .join('')
    .toUpperCase()
    .slice(0, 2);
}

// Generate color from name
function getColorFromName(name: string): string {
  const colors = ['bg-blue-500', 'bg-green-500', 'bg-purple-500', 'bg-orange-500'];
  const hash = name.split('').reduce((acc, char) => acc + char.charCodeAt(0), 0);
  return colors[hash % colors.length];
}
```
