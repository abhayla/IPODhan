# Story 9.11: SME IPO Performance Tracker Page

## Status
Done ✅

## Story

**As a** investor interested in SME IPO post-listing performance,
**I want** to view a comprehensive performance tracker showing listing day gains and current profit/loss for SME IPOs,
**so that** I can analyze how SME IPOs have performed since listing, identify successful listings, and make informed investment decisions based on historical performance data.

## Acceptance Criteria

1. SME Performance tracker page accessible at `/sme-ipo-performance-tracker`
2. Table displays all 7 columns with correct SME IPO data only
3. Year filter works correctly (default: current year)
4. Year filter updates URL query params
5. Only SME IPOs displayed (category=SME filter applied)
6. Color coding applied correctly:
   - Green for positive percentages
   - Red for negative percentages
7. "IPO Detail" links navigate to respective IPO detail pages
8. "Stock Quotes" links functional (external or internal)
9. Calculations are accurate:
   - Listing Day Gain = ((listingClose - issuePrice) / issuePrice) × 100
   - Profit/Loss = ((currentPrice - issuePrice) / issuePrice) × 100
10. IPOs sorted by listing date (descending)
11. Page uses ISR with 5-minute revalidation
12. Responsive: table on desktop, compact cards on mobile
13. Empty state shows "No SME IPOs listed in [year]" message
14. Loading skeleton displays during data fetch
15. SEO metadata configured (title, description, keywords)
16. Navigation link added to "SME IPOs" submenu
17. Performance data displays with 2 decimal precision for percentages
18. Rupee symbol (₹) displayed correctly for prices
19. Expandable company name links (IPO Detail and Stock Quotes)
20. Sorting by listing date (descending - newest first)
21. Year filter component reused from Story 9.7a

      const currentPrice = ipo.listingPerformance?.currentPrice || null;

**ListingPerformance Entity** [Source: docs/architecture/data-models.md]:
```typescript
export interface ListingPerformance {
  id: string;
  ipoId: string;
  listingPrice: number;          // Closing price on listing day
  issuePrice: number;            // IPO issue price (may also be in IPO table)
  listingGainPercent: number;    // Pre-calculated: ((listingPrice - issuePrice) / issuePrice) × 100
  currentPrice: number | null;   // Current market price (updated periodically)
  currentGainPercent: number | null; // Pre-calculated: ((currentPrice - issuePrice) / issuePrice) × 100
  lastUpdated: Date;             // When currentPrice was last updated
}
```

**Performance Calculations** [Source: Epic 9 Story 9.11]:
- **Listing Day Gain**: `((listingClose - issuePrice) / issuePrice) × 100`
- **Current Profit/Loss**: `((currentPrice - issuePrice) / issuePrice) × 100`
- Both calculations should result in 2 decimal precision
- Positive values = gains (green color)
- Negative values = losses (red color)

**Data Requirements**:
- IPO table with `category=SME` and `status=LISTED`
- ListingPerformance table with JOIN on `ipoId`

### ISR Configuration

**Incremental Static Regeneration** [Source: Story 9.7a]:
- Enable with: `export const revalidate = 300;` (5 minutes)
- How it works:
  1. Page generated statically at build time
  2. First request serves cached page (instant)
  3. After 5 minutes, next request triggers background regeneration
  4. Stale page served while regenerating
  5. New page cached and served to subsequent requests
- Benefits:
  - Fast page loads (static serving)
  - Fresh data (5-minute updates for current prices)
  - Low server load (caching)
  - SEO-friendly (static HTML)
