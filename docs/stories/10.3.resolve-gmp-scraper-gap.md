### Technical Details

**GMP (Grey Market Premium)**:
- Definition: Unofficial premium at which IPO shares trade before listing
- Data Points: Current GMP value, GMP percentage, historical trends
- Sources: Typically scraped from financial websites or aggregator APIs
- Importance: Helps investors gauge IPO demand and expected listing gains

**Database Schema Requirements**:

`gmp_tracking` table:
```sql
CREATE TABLE IF NOT EXISTS gmp_tracking (
  id SERIAL PRIMARY KEY,
  ipo_id INTEGER NOT NULL REFERENCES ipos(id) ON DELETE CASCADE,
  gmp_value DECIMAL(10, 2),           -- Absolute GMP in rupees
  gmp_percentage DECIMAL(5, 2),       -- GMP as % of issue price
  recorded_at TIMESTAMP DEFAULT NOW(),
  source VARCHAR(255),                 -- Data source identifier
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(ipo_id, recorded_at)         -- Prevent duplicate entries
);
```

`ipos` table (GMP fields):
```sql
ALTER TABLE ipos ADD COLUMN IF NOT EXISTS gmp DECIMAL(10, 2);
ALTER TABLE ipos ADD COLUMN IF NOT EXISTS gmp_percentage DECIMAL(5, 2);
ALTER TABLE ipos ADD COLUMN IF NOT EXISTS gmp_updated_at TIMESTAMP;
```

```typescript
  const { data: gmpData, isLoading, error } = useGMPData(ipoId);

  if (isLoading) {
```

**Pre-commit Hook** (suggested):
```bash
#!/bin/bash
# .git/hooks/pre-commit-docs-check

# Check for references to non-existent files in markdown docs
grep -r "lib/scrapers" docs/*.md | while read line; do
  file=$(echo $line | grep -o "lib/scrapers/[^)]*")
```
