### Data Models
[Source: architecture/data-models.md#ipo-core-entity]
The IPO interface includes:
```typescript
export interface IPO {
  id: string;
  companyName: string;
  slug: string;
  category: IPOCategory;
  sector: string;
  issueSize: number;
  priceRange: PriceRange;
  lotSize: number;
  status: IPOStatus;
  dates: IPODates;
  companyDescription: string;
  faceValue: number;
  listingExchanges: ('NSE' | 'BSE')[];
  registrar: string;
  leadManagers: string[];
  rating: number | null;
  ratingRationale: string | null;
  createdAt: Date;
  updatedAt: Date;
}
```

[Source: architecture/data-models.md#subscription]
Subscription interface tracks category-wise subscription data:
- High-level categories: QIB, NII, Retail, Employee, Others, Total
- Each category has `timesSubscribed` field (e.g., 45.2 for "45.2x")

[Source: architecture/data-models.md#gmprecord]
GMPRecord interface for 7-day GMP history:
```typescript
export interface GMPRecord {
  id: string;
  ipoId: string;
  price: number;           // Grey market premium price
  timestamp: Date;
  subjectRate: number | null;
  kostakRate: number | null;
}
```

[Source: architecture/data-models.md#financialdata]
FinancialData interface contains 3-year trends:
- Revenue (Year 1, 2, 3)
- Net Profit (Year 1, 2, 3)
- EPS, Diluted EPS, P/E Ratio, RoNW, NAV, P/BV
