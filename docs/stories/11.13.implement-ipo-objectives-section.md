## Business Context

### Problem Statement

Currently, IPODhan does not display "Objects of the Issue" (fund utilization breakdown) on IPO detail pages - a **critical transparency feature** that investors use to understand how IPO funds will be deployed.

**Current Coverage:** 0% (NOT IMPLEMENTED)

**Competitive Gap:** Chittorgarh shows IPO objectives prominently with detailed breakdowns

### Investor Value

- **Transparency:** Understand exactly how company plans to use raised capital
- **Risk Assessment:** Evaluate if fund usage aligns with investment thesis
- **Compliance:** Meet regulatory disclosure expectations
- **Trust:** Professional presentation builds investor confidence

### User Story

**As an** investor evaluating an IPO
**I want to** see a clear breakdown of how the company plans to use the IPO proceeds
**So that** I can assess if the fund utilization aligns with my investment goals

---

## Business Requirements

### What to Implement

1. **IPO Objectives Display Section**
   - Show "Objects of the Issue" table
   - Display S.No, Objective Description, Expected Amount (₹ Crores)
   - Calculate and show total amount allocated
   - Show any unallocated/general corporate purposes amount

2. **Example Display**:
   ```
   Objects of the Issue

   S.No | Objective Description                | Amount (₹ Cr)
   -----|--------------------------------------|---------------
   1    | Repayment of debt                   | ₹500.00
   2    | Working capital requirements        | ₹300.00
   3    | Capital expenditure                 | ₹200.00
   4    | General corporate purposes          | ₹150.00
   -----|--------------------------------------|---------------
        | TOTAL                                | ₹1,150.00
   ```

3. **Data Structure**:
   - Objectives stored as JSONB array
   - Each objective: serial number, description, amount
   - Null amounts for "unallocated" purposes

## Technical Requirements

### Database Schema Changes

**Table:** `ipo_details`
**Column to Add:** `objectives` JSONB

```sql
-- Migration: add-ipo-objectives
ALTER TABLE ipo_details
  ADD COLUMN objectives JSONB;

COMMENT ON COLUMN ipo_details.objectives IS 'Array of IPO fund utilization objectives [{sno: 1, description: "...", amount: 500}, ...]';
```

**JSONB Structure:**
```typescript
interface IPOObjective {
  sno: number;                  // Serial number (1, 2, 3...)
  description: string;          // Objective description
  amount: number | null;        // Amount in crores (null for unallocated)
}

// Example:
objectives: IPOObjective[] = [
  { sno: 1, description: "Repayment of debt", amount: 500.50 },
  { sno: 2, description: "Working capital", amount: 300.00 },
  { sno: 3, description: "Capital expenditure", amount: 200.00 },
  { sno: 4, description: "General corporate purposes", amount: null }
]
```

### UI Component Specifications

**Component:** `IPOObjectivesSection.tsx`

**Location:** `web/components/ipo-detail/IPOObjectivesSection.tsx`

**Component Structure:**
```typescript
interface IPOObjectivesSectionProps {
  objectives: IPOObjective[] | null;
  totalIssueSize?: number;  // For validation
}

export function IPOObjectivesSection({ objectives, totalIssueSize }: IPOObjectivesSectionProps) {
  // Empty state
  if (!objectives || objectives.length === 0) {
    return <EmptyState message="IPO objectives not available" />;
  }

  // Calculate total allocated
  const totalAllocated = objectives
    .filter(obj => obj.amount !== null)
    .reduce((sum, obj) => sum + (obj.amount || 0), 0);

  return (
    <section className="ipo-objectives">
      <h3>Objects of the Issue</h3>
      <table>
        <thead>
          <tr>
            <th>S.No</th>
            <th>Objective Description</th>
            <th>Amount (₹ Crores)</th>
          </tr>
        </thead>
        <tbody>
          {objectives.map(obj => (
            <tr key={obj.sno}>
              <td>{obj.sno}</td>
              <td>{obj.description}</td>
              <td>{obj.amount !== null ? `₹${obj.amount.toFixed(2)}` : '—'}</td>
            </tr>
          ))}
        </tbody>
        <tfoot>
          <tr>
            <td colSpan={2}><strong>TOTAL ALLOCATED</strong></td>
            <td><strong>₹{totalAllocated.toFixed(2)} Cr</strong></td>
          </tr>
        </tfoot>
      </table>
    </section>
  );
}
```

**Integration Point:**
- Place in **Overview tab** after Issue Structure section
- Alternative: Dedicated "Use of Proceeds" tab

## Risks & Mitigation

### Risk 1: JSONB Performance on Large Datasets
**Risk:** JSONB queries may be slower than structured columns
**Impact:** Low (IPO objectives are small arrays, <10 items)
**Mitigation:** Use GIN index if performance issues arise

### Risk 2: Data Entry Errors (Manual Admin Entry)
**Risk:** Admin may enter incorrect or inconsistent data
**Impact:** Medium (poor user experience)
**Mitigation:** Add strict validation, input hints, and preview feature

### Risk 3: Responsive Design on Mobile
**Risk:** 3-column table may not render well on small screens
**Impact:** Low
**Mitigation:** Use responsive table design (stack on mobile) or horizontal scroll
