## Critical Issues

### 🔴 Issue #1: Schema Drift - `ipo_details` Table Missing from Shared Schema

**Severity:** CRITICAL - BLOCKING

**Problem:**
The story assumes the `ipo_details` table is defined in `packages/shared/src/db/schema.ts`, but it is NOT present in that file. The table DOES exist in the actual database (confirmed in `web/drizzle/migrations/schema.ts`), creating a schema drift issue.

**Evidence:**
1. ✅ Table exists in database: `web/drizzle/migrations/schema.ts` lines 222-255
2. ❌ Table missing from shared schema: `packages/shared/src/db/schema.ts` (verified via grep)
3. ❌ No relations defined for `ipoDetails` in shared schema

**Impact:**
- TypeScript will not recognize `ipoDetails` table when building
- Repository queries referencing `schema.ipoDetails` will fail compilation
- Drizzle ORM queries won't work (line 366 in Dev Notes references non-existent table)
- Build will fail when dev agent tries to implement

**CLAUDE.md Violation:**
This violates the core architecture principle stated in CLAUDE.md:
> "The database schema has been consolidated into a **single source of truth** at `packages/shared/src/db/schema.ts`"

**Required Fix:**
1. Add `ipoDetails` table definition to `packages/shared/src/db/schema.ts`
2. Add relation between `ipos` and `ipoDetails` in `iposRelations`
3. Rebuild TypeScript project references: `npx tsc --build packages/shared`
4. Add new Task 0 as prerequisite: "Sync ipo_details table to shared schema"

**Database Fields Confirmed (from migrations/schema.ts:222-255):**
```typescript
- id: uuid (primary key)
- ipoId: uuid (foreign key to ipos.id)
- isin: varchar(12)
- issueType: varchar(20) - CHECK: ['BOOK_BUILDING', 'FIXED_PRICE', 'HYBRID']
- freshIssue: numeric(12, 2)
- ofsIssue: numeric(12, 2)
- cutOffPrice: numeric(10, 2)
- minInvestment: numeric(12, 2)
- registrarLink: varchar(500)
- faceValue: numeric(10, 2)
- basisOfAllotmentDate: date
- initiationOfRefundsDate: date
- creditOfSharesDate: date
- leadManagers: text[]
- exchanges: text[]
- companyDescription: text
- dataSource: varchar(50)
- lastVerifiedAt: timestamp
- createdAt: timestamp
- updatedAt: timestamp
```

All fields referenced in the story (issueType, freshIssue, ofsIssue, cutOffPrice, minInvestment, registrarLink) are confirmed to exist in the database table.
