# Story 4.11: Issue Structure Section

## Status
Ready (Updated after PO Review)

## ⚠️ IMPORTANT PREREQUISITE
**Task 0 MUST be completed first** - The `ipo_details` table exists in the database but is missing from the shared schema. Schema synchronization is required before implementation.

## Story

**As a** IPO investor,
**I want** to see the detailed issue structure breakdown (Fresh Issue vs OFS, issue type, minimum investment, cut-off price),
**so that** I can understand the offering mechanics and determine my investment eligibility and strategy.

## Acceptance Criteria

1. **Issue Structure Section in IPO Detail Page**
   - New "Issue Structure" section added to IPO Detail page
   - Position: After "Key Metrics" section, before "Financials" tab
   - Display in card/panel format
   - Responsive design (stacked on mobile, 2-column on desktop)

2. **Fresh Issue vs OFS Breakdown**
   - Display `fresh_issue` amount (capital raised for company)
   - Display `ofs_issue` amount (Offer for Sale - existing shareholders selling)
   - Show breakdown as percentage of total issue size
   - Visual representation: Pie chart or stacked bar chart
   - Labels: "Fresh Issue: ₹X Cr (Y%)" and "OFS: ₹X Cr (Y%)"
   - Tooltip explaining difference between Fresh Issue and OFS

3. **Issue Type Badge Display**
   - Display `issue_type` as prominent badge
   - Values: BOOK_BUILDING, FIXED_PRICE, HYBRID
   - Color coding:
     - BOOK_BUILDING: blue
     - FIXED_PRICE: green
     - HYBRID: purple
   - Tooltip explaining each type
   - Position: Top-right of Issue Structure section

4. **Minimum Investment Display**
   - Show `min_investment` amount prominently
   - Calculate from: lot_size × price_band_low
   - Display format: "Minimum Investment: ₹14,000"
   - Large, bold text to draw attention
   - Highlight if minimum is unusually high (>₹50,000)

5. **Cut-Off Price Display**
   - Show `cut_off_price` if available
   - Label: "Cut-off Price: ₹X"
   - Only display if IPO allows cut-off price bidding
   - Tooltip: "Cut-off price allows investors to bid at final discovered price"
   - Show "N/A" if not applicable

6. **Registrar Portal Link**
   - Display direct link to `registrar_link` portal
   - Button: "Visit Registrar Portal" with external link icon
   - Opens in new tab
   - Only show if registrar_link exists
   - Prominent placement below issue structure details

7. **Null Data Handling**
   - If ofs_issue is null/0, show only Fresh Issue (100%)
   - If fresh_issue is null/0, show only OFS (100%)
   - If both are null, show total issue_size without breakdown
   - If cut_off_price is null, hide that field
   - If registrar_link is null, hide the link button

## Dev Notes

### Database Context
[Source: screen-table-database-field-mapping.md#detailed-issue-structure]

**ipo_details Table - Issue Structure Fields:**

**Table Structure:**
- `id` (UUID) - Primary key
- `ipo_id` (UUID) - Foreign key to ipos table

**Issue Structure Fields:**
- `issue_type` (ENUM) - BOOK_BUILDING | FIXED_PRICE | HYBRID
  - BOOK_BUILDING: Price discovered through bidding (most common)
  - FIXED_PRICE: Fixed price set by issuer
  - HYBRID: Mix of both methods

- `fresh_issue` (NUMERIC, in crores) - Capital raised for company use
  - Goes to company for expansion/operations
  - Dilutes existing shareholders

- `ofs_issue` (NUMERIC, in crores) - Offer for Sale amount
  - Existing shareholders selling their stake
  - Money goes to selling shareholders, not company
  - No dilution, just ownership transfer

- `cut_off_price` (NUMERIC) - Cut-off price option
  - Allows retail investors to bid at final discovered price
  - Only applicable in BOOK_BUILDING type
  - NULL if not applicable

- `min_investment` (NUMERIC) - Minimum investment amount
  - Usually calculated as: lot_size × price_band_low
  - Important for investor eligibility

- `registrar_link` (VARCHAR) - Direct portal URL
  - Link to registrar's application/allotment portal
  - Varies by IPO (different registrars)

**Current Status:** These fields exist in ipo_details table but are NOT displayed in UI. Missing key information about offering mechanics.

### Repository Pattern Context
[Source: CLAUDE.md#repository-pattern-with-caching]

**Repository Join Query (AFTER Task 0 completion):**

```typescript
// web/lib/repositories/ipo-repository.ts
// NOTE: Requires ipo_details table in shared schema (Task 0 must be completed first)
import * as schema from '@ipodhan/shared/db/schema';

async findBySlug(slug: string): Promise<IPO | null> {
  const cacheKey = getIPOBySlugKey(slug);
  return this.getFromCache(cacheKey, async () => {
    const result = await this.db
      .select({
        ...schema.ipos,
        // Join ipo_details for issue structure
        issueType: schema.ipoDetails.issueType,
        freshIssue: schema.ipoDetails.freshIssue,
        ofsIssue: schema.ipoDetails.ofsIssue,
        cutOffPrice: schema.ipoDetails.cutOffPrice,
        minInvestment: schema.ipoDetails.minInvestment,
        registrarLink: schema.ipoDetails.registrarLink,
        isin: schema.ipoDetails.isin
      })
      .from(schema.ipos)
      .leftJoin(schema.ipoDetails, eq(schema.ipos.id, schema.ipoDetails.ipoId))
      .where(eq(schema.ipos.slug, slug))
      .limit(1);
    return result[0] || null;
  }, CacheTTL.IPO_DETAIL);
}
```

### Chart Implementation

import { PieChart, Pie, Cell, Legend, Tooltip } from 'recharts';

const COLORS = {
  freshIssue: '#10b981', // green
  ofs: '#3b82f6'         // blue
};

      <Pie data={data} dataKey="value" nameKey="name" cx="50%" cy="50%" outerRadius={80}>

        ))}
      </Pie>
      <Tooltip formatter={(value) => `₹${value} Cr`} />
      <Legend />
    </PieChart>
  );

### Educational Tooltips

**Fresh Issue vs OFS Explanation:**
- **Fresh Issue:** "New shares issued by the company. Capital raised goes to the company for business expansion, debt repayment, or working capital. This dilutes existing shareholders' ownership percentage."

- **OFS (Offer for Sale):** "Existing shareholders (promoters, investors, or employees) selling their stake. Money goes to selling shareholders, not the company. Company doesn't raise new capital. No dilution of ownership."

**Issue Type Explanations:**
- **Book Building:** "Price is not fixed upfront. Investors bid within a price range, and final price is determined based on demand. Most common method for large IPOs."

- **Fixed Price:** "Issuer sets a fixed price beforehand. Investors know exact price when applying. Common for smaller IPOs and retail-focused offerings."

- **Hybrid:** "Combination of both methods. Often used when a portion is fixed price (for retail) and rest is book-built (for institutions)."
