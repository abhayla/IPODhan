## Story
**As a** potential IPO investor searching for IPO information online,
**I want** IPODhan pages to appear in search results with rich, accurate information and fast loading times,
**so that** I can discover the platform organically and access IPO data quickly without experiencing performance issues.

## Acceptance Criteria
1. All pages have unique, optimized title tags (50-60 chars) with proper keyword placement
2. All pages have unique, compelling meta descriptions (150-160 chars) with value proposition
3. Open Graph tags configured for all pages with proper social sharing images (1200x630px)
4. Twitter Card tags configured for enhanced social sharing on all pages
5. Organization schema (JSON-LD) implemented on homepage with proper structured data
6. IPO entity schema (FinancialProduct) implemented on all IPO detail pages with valid structured data
7. BreadcrumbList schema implemented on navigation throughout the site
8. XML sitemap generated dynamically with all public pages (homepage, IPO listings, IPO details, tools, registrars)
9. Robots.txt configured correctly to allow indexing while blocking /api/ and /admin/
10. Canonical URLs set on all pages to prevent duplicate content issues
11. All images optimized (WebP format with fallback, lazy loading, descriptive alt text)
12. Internal linking strategy implemented (homepage to IPOs, IPO list to details, cross-links to tools)
13. Core Web Vitals passing: LCP <2.5s, FID <100ms, CLS <0.1 on real devices
14. Mobile-friendly test passing with Google's Mobile-Friendly Test tool
15. HTTPS configuration documented and SSL certificate requirements defined (Note: Actual SSL setup and validation occurs in Story 8.4 - Cloudflare & Analytics Setup. This story documents requirements only.)
16. Google Search Console: No errors, all pages successfully indexed
17. Rich results test: Structured data validated with no errors
18. Lighthouse SEO score: >95 on all major pages

- Next.js 14.2+ with App Router for file-based routing and built-in SEO support

- Static routes for tools, registrars, and other pages
- [Source: architecture/tech-stack.md#technology-stack-table, architecture/frontend-architecture.md#routing-architecture]

- Next.js 14 provides built-in `generateMetadata()` function for dynamic metadata
