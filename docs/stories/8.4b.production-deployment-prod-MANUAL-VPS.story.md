## Story
**As a** platform administrator deploying to production,
**I want** the IPODhan application deployed to Windows VPS (103.118.16.189) with PM2, PostgreSQL, Redis, and Cloudflare configured,
**so that** the site is live at https://ipodhan.com with secure, scalable, and reliable infrastructure.

## Acceptance Criteria
1. Site accessible at https://ipodhan.com with valid SSL certificate (A+ rating on SSL Labs)
2. PM2 running both apps successfully: ipodhan-web (2 instances, cluster mode) and ipodhan-scraper (1 instance, fork mode)
3. Scraper executing on schedule and updating database
4. Database (PostgreSQL) and Cache (Redis) connected and accessible
5. Cloudflare caching active and verified in response headers
6. Production environment variables configured securely on VPS (not in Git)
7. Auto-restart on crash enabled for both PM2 apps
8. Log rotation enabled for PM2 logs
9. Health check endpoint (`/api/health`) responding with status of database and Redis
10. Rollback procedure tested and verified

## Prerequisites (from Story 8.4a)
- ✅ PM2 ecosystem.config.js created
- ✅ Health check endpoint implemented
- ✅ .env.production.template created
- ✅ Deployment package script created
- ✅ Production builds verified locally
- ✅ Documentation created (README, ROLLBACK.md, checklist)

  - [ ] Set encryption mode to "Full (strict)"
  - [ ] Enable "Always Use HTTPS"

  - [ ] Wait for certificate provisioning (1-5 minutes)

    - URL: `ipodhan.com/api/*`

  - [ ] Create page rule for IPO pages:
    - URL: `ipodhan.com/ipos/*`
    - Cache Level: Cache Everything
    - Edge Cache TTL: 5 minutes
  - [ ] Enable "Auto Minify" for HTML, CSS, JavaScript
  - [ ] Enable "Brotli" compression

- [ ] Configure Cloudflare security settings (AC: 1)

### Troubleshooting

**Common Issues:**

1. **PM2 apps not starting:**
   - Check logs: `pm2 logs [app-name]`
   - Verify environment variables in .env.production
   - Check Node.js version: `node --version`

2. **Database connection errors:**
   - Verify DATABASE_URL is correct
   - Test connection: `psql -U ipodhan_user -d ipodhan`
   - Check PostgreSQL service is running

3. **Redis connection errors:**
   - Verify REDIS_URL is correct
   - Test connection: `redis-cli ping`
   - Check Redis service is running

4. **SSL issues:**
   - Verify Cloudflare SSL mode is "Full (strict)"
   - Check certificate provisioning in Cloudflare
   - Ensure HTTPS is enforced

5. **Site not accessible:**
   - Check DNS propagation: `nslookup ipodhan.com`
   - Verify VPS firewall allows ports 80/443
   - Check PM2 apps are running: `pm2 status`
