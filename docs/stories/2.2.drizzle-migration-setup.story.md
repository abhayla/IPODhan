### Drizzle Kit Migration Workflow
**Source:** `docs/architecture.md` lines 809-810, 1077-1080, 1171-1172

**Migration Strategy:** Migration-based schema management using Drizzle Kit

**Key Architecture Points:**
1. **Drizzle ORM:** Version 0.30+ (from tech stack, line 187)
2. **Migration Tool:** drizzle-kit for migration generation and application
3. **Migration Storage:** Type-safe schema definitions in `lib/db/schema.ts`
4. **Migration Execution:** Command: `npm run migrate` (line 1172)

**Migration Process:**
1. Schema changes made in `lib/db/schema.ts`
2. Generate migration: `drizzle-kit generate`
3. Review generated SQL in `drizzle/migrations/`
4. Apply migration: `drizzle-kit migrate`

### Drizzle Kit Configuration
**Source:** Drizzle ORM documentation patterns

**Required Configuration (`drizzle.config.ts`):**
```typescript
import type { Config } from 'drizzle-kit';

export default {
  schema: './lib/db/schema.ts',
  out: './drizzle/migrations',
  dialect: 'postgresql',
  dbCredentials: {
    connectionString: process.env.DATABASE_URL!,
  },
} satisfies Config;
```

**Environment Variables (from Story 1.2):**

### PostgreSQL Extensions Required
**Source:** `docs/architecture.md` line 966, Story 2.1 Dev Notes line 331

**Extensions Needed:**
1. **pg_trgm** - Trigram matching for fuzzy text search
   - Purpose: Enable fuzzy company name search
   - Usage: GIN index on `ipos.company_name`
   - SQL: `CREATE EXTENSION IF NOT EXISTS "pg_trgm";`

2. **uuid-ossp** - UUID generation (if not using `gen_random_uuid()`)
   - Purpose: Generate UUIDs for primary keys
   - SQL: `CREATE EXTENSION IF NOT EXISTS "uuid-ossp";`
   - Note: PostgreSQL 13+ has `gen_random_uuid()` built-in

### Trigram Index for Company Name
**Source:** Story 2.1 Dev Notes lines 324-331

**Index Specification:**
- Table: `ipos`
- Column: `company_name`
- Index name: `idx_ipos_company_name_trgm`
- Type: GIN (Generalized Inverted Index)
- Operator class: `gin_trgm_ops`
- Purpose: Fast fuzzy text search for company names (e.g., "HDFC" matches "HDFC Bank")

**SQL Statement:**
```sql
CREATE INDEX idx_ipos_company_name_trgm
ON ipos
USING gin(company_name gin_trgm_ops);
```

**Note in Schema:** Update `web/lib/db/schema.ts` comment (line 88) to reference this migration

- `db:migrate` - Apply pending migrations to database

- `db:studio` - Open Drizzle Studio (visual database editor)

**Example Usage:**
