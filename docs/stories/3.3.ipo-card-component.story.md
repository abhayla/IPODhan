## Story
**As a** user browsing IPOs,
**I want** to see IPO information displayed in clear, attractive cards,
**so that** I can quickly scan key details (name, status, price range, dates, rating) and select an IPO for more information.

## Acceptance Criteria
1. IPOCard component created at `web/src/components/ipo/IPOCard.tsx`
2. Display: company name, status badge, price range, lot size, open/close dates, IPODhan rating
3. Responsive layout: 1 column (mobile), 2 columns (tablet), 3 columns (desktop)
4. Hover effects: subtle elevation and border highlight on hover
5. Click handler: navigates to IPO detail page (`/ipos/[slug]`)
6. Unit tests with >80% coverage

**Display Requirements:**

1. **Company Name** (Heading)
   - Font: Bold, prominent
   - Truncate if exceeds container width
   - Accessible: h3 or h4 semantic HTML

2. **Status Badge** (Color-coded)
   - UPCOMING: Blue background (#3b82f6)
   - OPEN: Green background (#10b981)
   - CLOSED: Gray background (#6b7280)
   - LISTED: Purple background (#8b5cf6)
   - Use shadcn/ui Badge component
   - Display status text: "Upcoming", "Open", "Closed", "Listed"

3. **Category Badge**
   - Display: MAINBOARD, SME, RIGHTS, NCD
   - Subtle styling (outlined or muted color)
   - Use shadcn/ui Badge component

4. **Price Range**
   - Format: ₹{min} - ₹{max}
   - Example: ₹100 - ₹120
   - Number formatting with commas for large numbers (₹1,000 - ₹1,500)

5. **Lot Size**
   - Label: "Lot Size"
   - Value: {lotSize} shares
   - Example: "125 shares"

6. **Dates**
   - Open Date: Format as "DD MMM YYYY" (e.g., "10 Jan 2025")
   - Close Date: Format as "DD MMM YYYY"
   - Layout: "Open: 10 Jan - Close: 12 Jan"

7. **Rating** (IPODhan Rating)
   - Display: 1-5 stars (★★★★☆ for 4.0)
   - If rating is null: Display "Not Rated" or hide rating section
   - Color: Gold/yellow for filled stars

export interface IPO {
  id: string;
  companyName: string;
  slug: string;
  category: IPOCategory;
  sector: string;
  issueSize: number;
  priceRange: PriceRange;
  lotSize: number;
  status: IPOStatus;
  dates: IPODates;
  rating: number | null;
  createdAt: Date;
  updatedAt: Date;
}

export enum IPOStatus {
  UPCOMING = 'UPCOMING',
  OPEN = 'OPEN',
  CLOSED = 'CLOSED',
  LISTED = 'LISTED'
}

export enum IPOCategory {
  MAINBOARD = 'MAINBOARD',
  SME = 'SME',
  RIGHTS = 'RIGHTS',
  NCD = 'NCD'
}

export interface PriceRange {
  min: number;
  max: number;
}

export interface IPODates {
  openDate: Date;
  closeDate: Date;
  allotmentDate: Date | null;
  listingDate: Date | null;
}
