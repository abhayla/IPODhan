## Context from Issue #2

### Current Situation
**Issue #2 Achievement**: 52% BSE IPO enrichment (13/25 IPOs)
- ✅ MAINBOARD/SME IPOs: Complete data from BSE detail pages
- ❌ Rights Issues (RI): No BSE detail pages available (8 IPOs)
- ❌ Debt Issues (DPI/NCD): No BSE detail pages available (4 IPOs)

### The Problem
Rights and Debt issues are scraped from BSE main listing table but missing enriched data:

**Data Available (Phase 1 - Main Table)**:
- ✅ Company name
- ✅ Open/close dates
- ✅ Price range
- ✅ Category (RIGHTS/NCD)
- ✅ Status

**Data Missing (Phase 2 - Detail Pages)**:
- ❌ Issue size (showing `0`)
- ❌ Lot size (defaulting to `100`)
- ❌ Face value (defaulting to `10`)
- ❌ Registrar information
- ❌ Lead managers
- ❌ Symbol/ISIN

### Business Impact
- **12 IPOs per month** with incomplete data (based on current BSE volume)
- Users cannot see critical investment decision data for Rights/Debt offerings
- Data quality gap vs competitors who may have this information

## Technical Implementation Notes

### Current BSE Scraper Flow

**Phase 1: Main Table Scraping** (✅ Working for RI/DPI)
```typescript
// bse-scraper.ts extracts RI/DPI from main table
if (typeOfIssue && typeOfIssue.toUpperCase().includes('RI')) {
  category = 'RIGHTS';
} else if (typeOfIssue && (typeOfIssue.toUpperCase().includes('DPI') ||
           typeOfIssue.toUpperCase().includes('DEBT'))) {
  category = 'NCD';
}
```

**Phase 2: Detail Page Enrichment** (❌ Not available for RI/DPI)
```typescript
// Lines 369-372 of bse-scraper.ts
if (!rawIPO.detailUrl) {
  logger.debug({ companyName: ipo.companyName }, 'No detail URL available');
  continue; // RI/DPI IPOs skip enrichment here
}
```

### Proposed Integration Point

```typescript
// New Phase 2B: Rights/Debt Alternative Source Enrichment
// After existing Phase 2 detail page scraping

// Identify RI/DPI IPOs that need enrichment
const rightsIPOs = scrapedIPOs.filter(ipo =>
  ipo.category === 'RIGHTS' && ipo.issueSize === 0
);
const debtIPOs = scrapedIPOs.filter(ipo =>
  ipo.category === 'NCD' && ipo.issueSize === 0
);

// Enrich Rights IPOs
if (rightsIPOs.length > 0) {
  const rightsEnrichment = await scrapeRightsIssueDetails(rightsIPOs);
  mergeRightsData(scrapedIPOs, rightsEnrichment);
}

// Enrich Debt IPOs
if (debtIPOs.length > 0) {
  const debtEnrichment = await scrapeDebtIssueDetails(debtIPOs);
  mergeDebtData(scrapedIPOs, debtEnrichment);
}
```

### Data Source Evaluation Criteria

For each potential source, evaluate:
1. **Coverage**: Does it include Rights/Debt issues?
2. **Completeness**: Does it have issue_size, lot_size, registrar?
3. **Accuracy**: Can we verify data against BSE announcements?
4. **Reliability**: Is the source consistently available?
5. **Legal Compliance**: Can we scrape without TOS violations?
