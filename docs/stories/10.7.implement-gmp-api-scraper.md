#### Fuzzy Matching Logic

**Source**: `web/lib/scrapers/sources/historical-ipo-scraper.ts` (lines 369-457)

1. **Normalize company names**: Remove "Ltd", "Limited", "Pvt", special characters, convert to lowercase
2. **Calculate Levenshtein distance**: Use `fast-levenshtein` package
3. **85% similarity threshold**: Match if similarity >= 85%
4. **Cache IPO list**: Avoid repeated database queries

**Example**:
```typescript
private normalizeCompanyName(name: string): string {
  return name
    .toLowerCase()
    .replace(/[^a-z0-9\s]/g, '')
    .replace(/\b(limited|ltd|inc|pvt|private|corporation|corp|company)\b/gi, '')
    .replace(/\s+/g, ' ')
    .trim();
}

private calculateSimilarity(str1: string, str2: string): number {
  const normalized1 = this.normalizeCompanyName(str1);
  const normalized2 = this.normalizeCompanyName(str2);

  if (normalized1 === normalized2) return 100;

  const distance = levenshtein.get(normalized1, normalized2);
  const maxLength = Math.max(normalized1.length, normalized2.length);

  return ((maxLength - distance) / maxLength) * 100;
}
```

### Technical Notes

#### GMP Data Lifecycle

1. **Scraping**: Run GMP scraper periodically (e.g., every 6 hours for active IPOs)
2. **Storage**: Insert into `gmp_tracking` (time-series) AND update `ipos.gmp` (latest value)
3. **Frontend Display**: IPO detail page fetches GMP history for trend chart
4. **Graceful Degradation**: Frontend already handles `gmpCount: 0` scenario (from Story 10.3)

#### Database Operations

**Insert GMP Record**:
```typescript
import { db } from '@/lib/db';
import { gmpTracking, ipos } from '@/lib/db/schema';
import { eq } from 'drizzle-orm';

// Insert into gmp_tracking (time-series)
await db.insert(gmpTracking).values({
  ipoId: matchedIpoId,
  gmpValue: gmpData.gmp,
  gmpPercentage: gmpData.gmpPercentage,
  recordedAt: new Date(),
  source: 'Chittorgarh',
  createdAt: new Date(),
});

// Update latest GMP in ipos table
await db.update(ipos)
  .set({
    gmp: gmpData.gmp,
    gmpPercentage: gmpData.gmpPercentage,
    gmpUpdatedAt: new Date(),
  })
  .where(eq(ipos.id, matchedIpoId));
```

#### Rate Limiting Strategy

- **3-second delay** between IPO requests (consistent with `historical-ipo-scraper.ts`)
- Use `await this.sleep(3000)` between iterations
- This prevents IP blocking and respects website rate limits
