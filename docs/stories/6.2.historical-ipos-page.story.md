## Story
**As a** Rahul (active investor) or Priya (newcomer investor),
**I want** to browse historical IPOs with filtering, sorting, and search capabilities on a dedicated page,
**so that** I can research past IPO performance, compare with current opportunities, learn from historical trends, and make better investment decisions.

## Acceptance Criteria
1. Historical IPOs page at `/history`
2. Desktop: Table view with sortable columns
3. Mobile: Card view with reused IPO Card component
4. Filters: Year, Sector, Listing Performance
5. Search bar filters by company name (debounced)
6. Sorting: Listing Date, Listing Gain %, Subscription
7. Pagination: 20 IPOs per page
8. Results count displayed and updates with filters
9. URL query params persist filter state
10. Empty state with "Clear filters" button
11. SEO: Meta tags and structured data
12. Loading states for data fetch
13. Mobile-responsive design

export interface HistoricalIPO {

### API Specifications
**Source:** [docs/stories/6.1.historical-ipos-api.story.md#api-specifications]

**Endpoint Details:**
- Method: GET
- Path: `/api/ipos/history`
- Query Parameters: year, sector, performance, sort, sortOrder, page, limit
- Response Type: `HistoricalIPOResponse`
- Cache TTL: 24 hours (86400 seconds)
- Rate Limit: 100 requests/minute per IP

**Query Parameters:**
- `year`: '2020' | '2021' | '2022' | '2023' | '2024' | '2025' | 'All' (default: 'All')
- `sector`: string (default: 'All')
- `performance`: 'All' | 'Positive' | 'Negative' (default: 'All')
- `sort`: 'listing_date' | 'listing_gain' | 'subscription' (default: 'listing_date')
- `sortOrder`: 'ASC' | 'DESC' (default: 'DESC')
- `page`: number (default: 1)
- `limit`: number (default: 20)

**Pagination:**
- Default: 20 IPOs per page
- API returns total count and total pages
- Page numbers start at 1

### State Management
**Source:** [docs/architecture/frontend-architecture.md#state-management-architecture]

**React Context Pattern:**
- Create `HistoricalFiltersContext` to manage filter state
- State includes: year, sector, performance, sort, sortOrder, searchQuery, page
- Update methods: setYear, setSector, setPerformance, setSort, setSearchQuery, setPage, clearFilters
- Sync state to URL query params using Next.js useSearchParams hook
- Parse URL query params on initial page load to restore state

**URL Query Params:**
- Pattern: `/history?year=2024&sector=Technology&performance=positive&sort=listing_gain&sortOrder=DESC&page=1`
- Enables shareable links
- Bookmarkable filter states
- Browser back/forward navigation

**Client-Side Refetch:**
- When filters change, trigger API refetch with new query params
- Use React state or SWR/TanStack Query for data fetching (if available)
- Display loading state during refetch
