## Story
**As a** user,
**I want** to see a simple 0-100 score for each IPO,
**so that** I can make quick investment decisions.

## Acceptance Criteria

**1. Score Components & Weightage:**

Score configuration with four weighted components:
- **Fundamentals (40%):** P/E ratio (8), Revenue growth (8), Profitability (8), Debt-to-equity (5), ROE (5), Cash flow (6)
- **Market Sentiment (30%):** GMP trend (10), Watchlist additions (5), Social buzz (5), Crowd prediction (5), Search trends (5)
- **Subscription (20%):** QIB subscription (8), HNI subscription (4), Retail subscription (5), Momentum (3)
- **Sector Timing (10%):** Sector performance (3), Peer comparison (3), Market condition (2), IPO capacity (2)

**2. Scoring Algorithm Implementation:**

Python class `IPOScoringEngine` with methods:
- `calculate_score(ipo_id)` → returns dict with total_score (0-100), component_scores, confidence, explanation
- `calculate_fundamentals(ipo_data)` → max 40 points
- `calculate_sentiment(ipo_data)` → max 30 points
- `calculate_subscription(ipo_data)` → max 20 points
- `calculate_sector(ipo_data)` → max 10 points

**3. Score Interpretation & Display:**

Score bands with recommendations:
- 70-100: "Strong Buy" (green 🟢)
- 50-69: "Consider" (yellow 🟡)
- 30-49: "Risky" (orange 🟠)
- 0-29: "Avoid" (red 🔴)

Each score includes: label, color, strengths, weaknesses, key factors

**4. SME IPO Adjustments:**

Special handling for SME category IPOs:
- Higher risk penalty: -5 points
- Lower liquidity penalty: -3 points
- Growth potential bonus: +8 points (if revenue growth >40%)
- Promoter holding bonus: +3 points (if post-IPO holding >60%)
- SME warning flag added to response

**5. Historical Score Tracking:**

Database table `score_history` with fields:
- ipo_id, total_score, component scores (fundamental, sentiment, subscription, sector)
- confidence_level, algorithm_version, calculated_at
- score_change (difference from previous), change_reason
- Index on (ipo_id, calculated_at DESC)

**6. Score Performance Tracking:**

Database table `score_performance` tracking prediction accuracy:
- predicted_score, actual_listing_gain, prediction_accuracy
- analyzed_at timestamp

**7. A/B Testing Framework:**

Python class `ScoreABTesting` with methods:
- `create_experiment(name, variants)` → creates test with variant configurations
- `get_variant(experiment_name, ipo_id)` → deterministically assigns IPO to variant
- `track_result(experiment_name, variant, score, outcome)` → records performance

**8. API Endpoints:**

- `GET /api/scores/{ipo_id}` → returns current score with breakdown
- `GET /api/scores/{ipo_id}/history` → returns historical scores
- `GET /api/scores/{ipo_id}/breakdown` → returns detailed component breakdown
- `POST /api/scores/{ipo_id}/recalculate` → triggers score recalculation

**9. Manual Override & Audit:**

Python class `ScoreOverride` with method:
- `apply_manual_override(ipo_id, override_data, reason, authorized_by)` → applies manual adjustment
- Logs all overrides with audit trail
- Stores original score, new score, reason, authorized_by, timestamp
- Updates score with is_override=True flag

**10. Score Update Schedule:**

Automated score calculation:
- 3 times daily (9:00 AM, 1:00 PM, 5:00 PM IST)
- Triggered automatically via scheduled task
- Updates stored in score_history table
- Latest score cached in Redis for fast retrieval

**11. Data Quality & Confidence:**

Confidence level assessment based on data completeness:
- HIGH: All required data available (>90% fields populated)
- MEDIUM: Most data available (60-90% fields populated)
- LOW: Limited data available (<60% fields populated)

**12. Performance Validation:**

- Score accuracy target: >70% correlation with actual listing gains
- Score recalculation: <2 seconds per IPO
- API response time: <500ms for score retrieval (with caching)

```python
from pydantic import BaseModel, ConfigDict, Field
from datetime import datetime
from typing import Literal

class ScoreComponents(BaseModel):
    fundamental: int = Field(ge=0, le=40)
    sentiment: int = Field(ge=0, le=30)
    subscription: int = Field(ge=0, le=20)
    sector: int = Field(ge=0, le=10)

class IPOScoreSchema(BaseModel):
    model_config = ConfigDict(validate_assignment=True)

    ipo_id: str
    total_score: int = Field(ge=0, le=100)
    components: ScoreComponents
    verdict: Literal['APPLY', 'CONSIDER', 'SKIP']
    confidence: Literal['HIGH', 'MEDIUM', 'LOW']
    reasoning: str
    calculated_at: datetime
```

```python
def calculate_fundamentals(self, ipo_data: dict) -> int:
    score = 0

    # P/E Ratio (8 points)
    pe_ratio = ipo_data.get('pe_ratio')
    industry_pe = ipo_data.get('industry_pe')
    if pe_ratio and industry_pe:
        if pe_ratio < industry_pe * 0.7:
            score += 8
        elif pe_ratio < industry_pe:
            score += 6
        elif pe_ratio < industry_pe * 1.2:
            score += 4
        else:
            score += 2

    # Revenue Growth (8 points) - 3-year CAGR
    revenue_growth = self.calculate_cagr(
        ipo_data.get('revenue_fy1'),
        ipo_data.get('revenue_fy3')
    )
    if revenue_growth > 30:
        score += 8
    elif revenue_growth > 20:
        score += 6
    elif revenue_growth > 10:
        score += 4
    else:
        score += 2

    # Continue for other components: profitability, debt, ROE, cash flow
    # (See Epic AC2 for complete logic)

    return min(score, 40)  # Cap at 40
```

**2. Market Sentiment (30 points):**
```python
def calculate_sentiment(self, ipo_data: dict) -> int:
    score = 0

    # GMP Trend (10 points)
    current_gmp = ipo_data.get('current_gmp_percent', 0)
    gmp_trend = ipo_data.get('gmp_7day_trend', 'stable')

    if current_gmp > 50:
        score += 7
    elif current_gmp > 30:
        score += 5
    elif current_gmp > 15:
        score += 3
    else:
        score += 1

    # Trend bonus
    if gmp_trend == 'increasing':
        score += 3
    elif gmp_trend == 'stable':
        score += 2

    # Continue for watchlist, social buzz, crowd prediction, search trends
    # (See Epic AC4 for complete logic)

    return min(score, 30)  # Cap at 30
```
