## Story
**As a** user browsing IPOs on the dashboard,
**I want** to search for IPOs by company name or sector using a search input with instant feedback,
**so that** I can quickly find specific IPOs I'm interested in without scrolling through all listings.

## Acceptance Criteria
1. Search input component integrated into dashboard header
2. Debounced search with 300ms delay to reduce API calls
3. Search by company name (case-insensitive, partial match)
4. Search by sector (case-insensitive, partial match)
5. Search highlights in results (highlight matching text in IPO cards)
6. Recent searches saved in localStorage (last 5 searches)
7. Clear search button (X icon) visible when search has text
8. No results state with helpful message when search returns empty
9. Search suggestions dropdown (future enhancement ready - optional for MVP)
10. Keyboard navigation support (Enter to search, Escape to clear)

### Frontend Architecture
**Source:** [docs/architecture/frontend-architecture.md]

**State Management Architecture:**

**URL State (Shareable, Bookmarkable):**
- Search query: `?search=reliance` (shareable search results)
- Combined with filters: `?status=OPEN&category=MAINBOARD&search=tech`
- Pagination: `?page=2` (reset to 1 when search changes)
- View preference: `?view=grid` or `?view=list`
- Full URL: `?search=reliance&status=OPEN&category=MAINBOARD&page=1&view=grid`

**Local Storage (Client-Side Persistence):**
- Recent searches: `localStorage.getItem('recent-searches')` (last 5 searches)
- No server-side state needed for search history

**Client Component Pattern:**
```typescript
// Client Component (components/dashboard/SearchBar.tsx)
'use client';

import { useState, useEffect } from 'react';
import { useRouter, useSearchParams } from 'next/navigation';
import { useDebounce } from '@/hooks/useDebounce';
import { saveSearch } from '@/lib/search-history';

export function SearchBar() {
  const router = useRouter();
  const searchParams = useSearchParams();
  const [searchInput, setSearchInput] = useState('');
  const debouncedSearch = useDebounce(searchInput, 300);

  // Read initial search from URL
  useEffect(() => {
    const initialSearch = searchParams.get('search') || '';
    setSearchInput(initialSearch);
  }, [searchParams]);

  // Update URL when debounced search changes
  useEffect(() => {
    if (debouncedSearch !== searchParams.get('search')) {
      const params = new URLSearchParams(searchParams);

      if (debouncedSearch) {
        params.set('search', debouncedSearch);
        saveSearch(debouncedSearch); // Save to localStorage
      } else {
        params.delete('search');
      }

      params.set('page', '1'); // Reset pagination
      router.push(`/dashboard?${params.toString()}`);
    }
  }, [debouncedSearch]);

  const handleClear = () => {
    setSearchInput('');
    const params = new URLSearchParams(searchParams);
    params.delete('search');
    params.set('page', '1');
    router.push(`/dashboard?${params.toString()}`);
  };

  return (
    <div className="relative">
      <Search className="absolute left-3 top-1/2 -translate-y-1/2 text-gray-400" />
      <input
        type="text"
        value={searchInput}
        onChange={(e) => setSearchInput(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === 'Escape') handleClear();
        }}
        placeholder="Search IPOs by company or sector..."
        className="w-full pl-10 pr-10 py-2 border rounded-lg"
      />
      {searchInput && (
        <button onClick={handleClear} className="absolute right-3 top-1/2 -translate-y-1/2">
          <X className="text-gray-400 hover:text-gray-600" />
        </button>
      )}
    </div>
  );
}
```

### Search Highlighting Implementation

**Utility Function:**
```typescript
// lib/utils.ts
export function highlightText(text: string, query: string): string {
  if (!query) return text;

  const regex = new RegExp(`(${escapeRegex(query)})`, 'gi');
  return text.replace(regex, '<mark class="bg-yellow-200 font-semibold">$1</mark>');
}

function escapeRegex(str: string): string {
  return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}
```

**Component Usage:**
```typescript
// components/search/HighlightedText.tsx
'use client';

interface HighlightedTextProps {
  text: string;
  query: string;
}

export function HighlightedText({ text, query }: HighlightedTextProps) {
  if (!query) return <span>{text}</span>;

  const parts = text.split(new RegExp(`(${escapeRegex(query)})`, 'gi'));

  return (
    <span>
      {parts.map((part, i) =>
        part.toLowerCase() === query.toLowerCase() ? (
          <mark key={i} className="bg-yellow-200 font-semibold">{part}</mark>
        ) : (
          <span key={i}>{part}</span>
        )
      )}
    </span>
  );
}
```

### Recent Search History (localStorage)

**Storage Implementation:**
```typescript
// lib/search-history.ts
const STORAGE_KEY = 'recent-searches';
const MAX_RECENT_SEARCHES = 5;

export function saveSearch(query: string): void {
  if (!query || query.trim().length < 2) return;

  const recent = getRecentSearches();
  const updated = [
    query,
    ...recent.filter(q => q.toLowerCase() !== query.toLowerCase())
  ].slice(0, MAX_RECENT_SEARCHES);

  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(updated));
  } catch (error) {
    console.error('Failed to save search history:', error);
  }
}

export function getRecentSearches(): string[] {
  try {
    const stored = localStorage.getItem(STORAGE_KEY);
    return stored ? JSON.parse(stored) : [];
  } catch (error) {
    console.error('Failed to load search history:', error);
    return [];
  }
}

export function clearSearchHistory(): void {
  try {
    localStorage.removeItem(STORAGE_KEY);
  } catch (error) {
    console.error('Failed to clear search history:', error);
  }
}
```

### Performance Considerations

**Client-Side Optimizations:**
- Debounce search input (300ms delay) to reduce API calls
- Cancel pending debounce on component unmount
- Memoize highlightText function to prevent re-renders
- Use React.memo for HighlightedText component
- Lazy load search suggestions (fetch only when needed)

**Backend Caching:**
- GET /api/ipos responses cached 5 minutes (already implemented in Story 3.2)
- GET /api/search/suggestions cached 10 minutes (implement if endpoint created)
- Cache key includes search query for accurate results
- Redis cache invalidation on IPO data updates

**Performance Targets:**
- Search input to URL update: <50ms (after 300ms debounce)
- Search query to new data display: <500ms
- Search highlighting: <50ms (client-side rendering)
- Recent searches load: <10ms (localStorage read)

**Optimization Notes:**
- Debouncing prevents excessive API calls (user typing fast)

### Search Flow

**User Interaction Flow:**
1. User opens dashboard → Reads search query from URL (if present) → Displays search results
2. User types in search input → Debounces 300ms → Updates URL param → Dashboard refetches data
3. User sees highlighted results → Company names and sectors show matching text
4. User clears search → Removes search param from URL → Shows all IPOs
5. User bookmarks URL → Returns later → Same search results restored

**URL Param Handling Logic:**
```typescript
// Reading URL params (Server Component)
const search = searchParams.search || undefined;

// Updating URL params (Client Component)
const updateSearch = (query: string) => {
  const params = new URLSearchParams(searchParams);

  if (query && query.trim().length >= 2) {
    params.set('search', query);
    saveSearch(query); // Save to localStorage
  } else {
    params.delete('search');
  }

  // Reset pagination
  params.set('page', '1');

  // Navigate with updated params
  router.push(`/dashboard?${params.toString()}`);
};
```

**Default Search Behavior:**
- Minimum query length: 2 characters (prevent single-letter searches)
- Search mode: Partial match (ILIKE '%query%')
- Search fields: company name OR sector
- Case-insensitive matching
- Reset page to 1 when search changes

**Search Combinations:**
- Search only: `?search=reliance`
- Search + status filter: `?search=tech&status=OPEN`
- Search + all filters: `?search=tech&status=OPEN&category=MAINBOARD&sector=Technology`
- Search + pagination: `?search=reliance&page=2`
- Search + view toggle: `?search=reliance&view=list`
