## Story
**As a** Priya (newcomer investor),
**I want** to know how many lots I can buy with my investment amount,
**so that** I can plan my IPO application accurately.

## Acceptance Criteria
1. Embedded calculator widget on IPO detail page
2. Standalone calculator page at `/tools/lot-calculator`
3. Input field accepts investment amount (₹ with comma separators, e.g., "₹15,000")
4. Calculator displays:
   - Number of lots
   - Total shares (formatted with commas, e.g., "1,500")
   - Total investment amount (rounded to lot size, formatted as "₹15,000")
5. Calculation formula: `lots = floor(investmentAmount / (lotSize * pricePerShare))`
6. Real-time calculation (updates as user types, debounced 300ms)
7. Pre-filled with IPO data when accessed from detail page
8. Dropdown to select any IPO on standalone page
9. Validation: Minimum investment = 1 lot
10. Error handling for invalid inputs (inline validation messages below input field)
11. Mobile-responsive design

### Data Models
**IPO Interface** [Source: docs/architecture/data-models.md#ipo-core-entity]:
```typescript
export interface IPO {
  id: string;
  companyName: string;
  slug: string;
  lotSize: number;
  priceRange: { min: number; max: number };
  status: IPOStatus;
  // ... other fields
}
```

**Calculator Request/Response** [Source: docs/architecture/api-specification.md#tools-calculators]:
```typescript
// POST /api/tools/lot-calculator
Request: {
  ipoSlug: string,
  investmentAmount: number
}

Response: {
  lots: number,
  totalShares: number,
  totalAmount: number,
  ipoDetails: {
    companyName: string,
    lotSize: number,
    priceRange: { min: number, max: number }
  }
}
```

### API Specifications
**Endpoint Details** [Source: docs/architecture/api-specification.md#tools-calculators]:
- Method: POST
- Path: `/api/tools/lot-calculator`
- Cache TTL: No caching (calculation endpoint)
- Rate Limit: 100 requests/minute per IP

**Calculation Formula** [Source: docs/stories/epics/epic-5-ipo-tools.md#51-lot-size-calculator]:
```
lots = floor(investmentAmount / (lotSize * priceRange.max))
totalShares = lots * lotSize
totalAmount = lots * lotSize * priceRange.max
```
Note: Use `priceRange.max` for conservative calculation (worst-case scenario for investor).
