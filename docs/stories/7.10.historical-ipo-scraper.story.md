## Story
**As a** IPODhan platform user,
**I want** access to comprehensive historical IPO performance data including subscription metrics, GMP, and listing gains,
**so that** I can analyze past IPO performance trends and make data-driven investment decisions based on historical patterns.

## Acceptance Criteria

1. Scraper successfully navigates to Chittorgarh IPO performance tracker (`https://www.chittorgarh.com/ipo/ipo-performance-tracker/`)
2. Scraper extracts historical IPO data for specified years (2020-2025)
3. Scraper extracts subscription data: Retail, HNI (High Net-Worth Individual), QIB (Qualified Institutional Buyer) subscription multiples
4. Scraper extracts Grey Market Premium (GMP) values: absolute value and percentage
5. Scraper extracts listing performance: listing price, listing gains (percentage and absolute)
6. Scraper extracts current market price and calculates current gains from issue price
7. Scraper matches scraped data to existing IPOs using fuzzy name matching (85% similarity threshold)
8. Scraper implements bulk upsert logic with batch processing (50 IPOs per batch) for performance optimization
9. Scraper handles incremental updates (only processes new/modified IPOs on subsequent runs)
10. Scraper implements retry logic for failed HTTP requests (3 retries with exponential backoff)
11. Scraper validates all numeric data using Zod schemas before database insertion
12. Scraper logs all operations (IPOs found, matched, validated, stored, failed) with structured logging
13. Scraper can be executed manually via CLI: `npm run scrape:historical`
14. Scraper implements rate limiting (3 seconds between year-wise requests) to prevent server overload

    ```typescript
    import levenshtein from 'fast-levenshtein';

    calculateSimilarity(str1: string, str2: string): number {
      const normalized1 = this.normalizeCompanyName(str1);
      const normalized2 = this.normalizeCompanyName(str2);

      if (normalized1 === normalized2) return 100;

      const distance = levenshtein.get(normalized1, normalized2);
      const maxLength = Math.max(normalized1.length, normalized2.length);
      return ((maxLength - distance) / maxLength) * 100;
    }
    ```

      const ipos = await this.fetchAllIPOs();

      let bestMatch: MatchResult = {
        ipoId: null,
        matchScore: 0,
        matched: false,
      };

      for (const ipo of ipos) {
        const score = this.calculateSimilarity(data.ipoName, ipo.companyName);

        if (score > bestMatch.matchScore) {

            ipoId: ipo.id,

      if (!bestMatch.matched) {
        this.log('No match found', {
          ipoName: data.ipoName,
          bestScore: bestMatch.matchScore
        });
      }

      return bestMatch;
    }

### Phase 5: Main Scraper Orchestration (AC: 12, 13)

  - [ ] Orchestration flow:
    ```typescript
    async scrape(options: {
      years?: number[],
      incrementalUpdate?: boolean
    } = {}): Promise<ScraperResult<HistoricalIPOData[]>> {
      try {
        this.logStart();

        // Step 1: Determine years to scrape
        const years = this.determineYearsToScrape(options);
        this.log(`Scraping ${years.length} years`, { years });

        // Step 2: Scrape each year with rate limiting (AC: 14)
        const allData: HistoricalIPOData[] = [];
        for (const year of years) {
          this.log(`Scraping year ${year}`);
          const yearData = await this.scrapeChittorgarh(year);
          allData.push(...yearData);

          // Rate limiting: 3 seconds between year requests
          if (years.indexOf(year) < years.length - 1) {
            await this.sleep(3000);
          }
        }
        this.log(`Found ${allData.length} total IPOs`);

        // Step 3: Validate all data
        const validData = allData
          .map(data => this.validateIPOData(data))
          .filter((data): data is HistoricalIPOData => data !== null);
        this.log(`Validated ${validData.length} IPOs`);

        // Step 4: Match to existing IPOs
        const matchedData = await this.matchAllData(validData);
        const matchedCount = matchedData.filter(d => d.ipoId).length;
        this.log(`Matched ${matchedCount}/${matchedData.length} IPOs`);

        // Step 5: Store in database with batch processing
        await this.storeHistoricalData(matchedData);
        this.log(`Stored ${matchedCount} IPOs in database`);

        this.logComplete(matchedData.length);
        return this.createSuccessResult(matchedData);
      } catch (error) {
        this.logError(error);
        return this.createErrorResult(error);
      }
    }
    ```

- [ ] Implement year determination logic

  - [ ] Logic:
    ```typescript
    private determineYearsToScrape(options: {
      years?: number[],
      incrementalUpdate?: boolean
    }): number[] {
      // Explicit years provided
      if (options.years && options.years.length > 0) {
        return options.years;
      }

      // Incremental update mode
      if (options.incrementalUpdate) {
        const currentYear = new Date().getFullYear();
        return [currentYear, currentYear - 1];
      }

      // Default: All years (2020-2025)
      const currentYear = new Date().getFullYear();
      const years: number[] = [];
      for (let year = 2020; year <= currentYear; year++) {
        years.push(year);
      }
      return years;
    }
    ```

    ```typescript
    import { historicalIPOScraper } from '@/lib/scrapers/sources/historical-ipo-scraper';

    async function main() {
      const args = process.argv.slice(2);

      // Parse command line arguments
      const options: {
        years?: number[],
        incrementalUpdate?: boolean
      } = {};

      if (args.includes('--incremental')) {
        options.incrementalUpdate = true;
        console.log('Running in incremental update mode...\n');
      } else if (args.includes('--years')) {
        const yearIndex = args.indexOf('--years') + 1;
        const yearArg = args[yearIndex];
        if (yearArg) {
          options.years = yearArg.split(',').map(y => parseInt(y.trim()));
          console.log(`Scraping specific years: ${options.years.join(', ')}\n`);
        }
      } else {
        console.log('Running full historical scrape (2020-2025)...\n');
      }

      console.log('Starting Historical IPO Data Scraper...\n');

      const result = await historicalIPOScraper.scrape(options);

      if (result.success) {
        console.log(`✅ Scraper completed successfully`);
        console.log(`   IPOs processed: ${result.data?.length || 0}`);
        const matched = result.data?.filter(d => d.ipoId).length || 0;
        console.log(`   IPOs matched: ${matched}`);
        console.log(`   Match rate: ${((matched / (result.data?.length || 1)) * 100).toFixed(1)}%`);
      } else {
        console.error(`❌ Scraper failed: ${result.error}`);
        process.exit(1);
      }
    }

    main().catch((error) => {
      console.error('Fatal error:', error);
      process.exit(1);
    });
    ```

### Technical Approach

**Large Dataset Challenge:**
Historical IPO data spans multiple years with potentially 200-300 IPOs total:
- 2020: ~30 IPOs
- 2021: ~50 IPOs
- 2022: ~35 IPOs
- 2023: ~60 IPOs
- 2024: ~70 IPOs
- 2025: ~30 IPOs (projected)

**Solution: Batch Processing**
- Process in batches of 50 IPOs per database transaction
- Reduces memory footprint
- Prevents database connection timeout
- Enables progress tracking

**Incremental Update Strategy:**
- **Initial Load**: Scrape all years (2020-2025) - Run once during setup
- **Daily Updates**: Scrape only current year + previous year - Captures new IPOs and updated listing data
- **Performance**: Initial load ~10 minutes, incremental update ~2 minutes

**Fuzzy Matching Complexity:**
Company names vary significantly across sources:
- Chittorgarh: "Tata Technologies Ltd"
- Database: "Tata Technologies Limited"
- Edge case: "Tech Corp" vs "Tech Corporation Private Limited"

**Solution: Enhanced Normalization**
```typescript
normalizeCompanyName(name: string): string {
  return name
    .toLowerCase()
    // Remove common suffixes
    .replace(/\b(limited|ltd|inc|pvt|private|corporation|corp|company|co)\b/gi, '')
    // Remove special characters
    .replace(/[^a-z0-9\s]/g, '')
    // Normalize whitespace
    .replace(/\s+/g, ' ')
    .trim();
}
```

**Data Accuracy Considerations:**
- **Subscription data**: Accurate for closed IPOs, not available for upcoming IPOs
- **GMP data**: Changes daily, represents grey market sentiment (not official)
- **Listing data**: Final once IPO lists, doesn't change
- **Current price**: Needs periodic updates (separate job recommended)

**Performance Optimization:**
- Year-wise scraping with 3 second delays (prevents rate limiting)
- Parallel processing within each year (if Chittorgarh supports it)
- Database caching for IPO matching (load once, reuse for all matches)
- Batch database updates (50 IPOs per transaction)
- Target execution time:
  - Full scrape (2020-2025): <10 minutes
  - Incremental (2 years): <2 minutes

### Error Handling

**Scraper-Level Errors:**
- Year page load failures: Retry 3 times with exponential backoff (1s, 2s, 4s)
- Parse errors: Log and continue with next IPO
- Validation errors: Skip invalid IPOs, log for manual review

**Matching Errors:**
- No match found (<85% similarity): Log unmatched IPO for manual review
- Multiple matches (edge case): Choose highest similarity score
- Abbreviation mismatches: Enhanced normalization handles most cases

**Database Errors:**
- Batch transaction failure: Retry entire batch once
- Foreign key violation: Skip IPO (should not happen if matching is correct)
- Connection timeout: Implement connection pooling and batch size reduction

**Rate Limiting Errors:**
- HTTP 429 (Too Many Requests): Increase delay to 5 seconds, retry
- HTTP 503 (Service Unavailable): Wait 30 seconds, retry
- Connection refused: Abort scraper, notify admin

### Known Limitations

**Data Availability:**
- GMP data may not be available for all IPOs (depends on grey market activity)
- Current price requires separate update mechanism (not always on performance tracker page)
- Historical data before 2020 may be incomplete

**Matching Challenges:**
- Parent company vs subsidiary names (e.g., "Tata Sons" vs "Tata Technologies")
- Name changes post-listing (requires manual mapping)
- Multilingual names (Hindi/English variations)

**Solution: Manual Mapping Table**
Create `ipo_name_mappings` table for edge cases:
```sql
CREATE TABLE ipo_name_mappings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  external_name VARCHAR(500) NOT NULL,
  ipo_id UUID NOT NULL REFERENCES ipos(id),
  source VARCHAR(100) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

Use mappings to handle known mismatches before fuzzy matching.
