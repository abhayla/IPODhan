## Story

**As a** user viewing IPO details,
**I want** complete IPO information including financials, subscriptions, and GMP data,
**so that** I can make informed investment decisions

## Acceptance Criteria

1. **AC-1**: IPO financials data populated in database
   - `ipo_financials` table contains data for active IPOs
   - Query `SELECT COUNT(*) FROM ipo_financials` returns > 0
   - Foreign key relationships to ipos table working
   - TEST-005-1 passes (financials data count verification)

2. **AC-2**: Subscription data populated in database
   - `subscriptions` table contains subscription data
   - Query `SELECT COUNT(*) FROM subscriptions` returns > 0
   - Data linked correctly to IPO records
   - TEST-005-2 passes (subscriptions data count verification)

3. **AC-3**: GMP tracking data populated (if scraper exists)
   - `gmp_tracking` table contains GMP history
   - Query `SELECT COUNT(*) FROM gmp_tracking` returns > 0 (if applicable)
   - GMP data linked to IPO records
   - TEST-005-3 passes (GMP data count verification)

4. **AC-4**: All scrapers run successfully
   - Historical IPO scraper executed without errors
   - Reviews scraper executed without errors
   - Other data scrapers completed successfully
   - Scraper logs reviewed for errors
   - TEST-005-4 passes (all scrapers run successfully)

5. **AC-5**: Foreign key relationships validated
   - All financials properly linked to ipos.id
   - All subscriptions properly linked to ipos.id
   - All GMP tracking properly linked to ipos.id
   - No orphaned records in related tables
   - TEST-005-5 passes (foreign key validation)

6. **AC-6**: Frontend displays populated data
   - IPO detail pages show hasFinancials=true
   - Subscription counts > 0 where applicable
   - GMP counts > 0 where applicable (if GMP scraper exists)
   - No "No data available" messages for populated records
   - TEST-005-6 passes (frontend data display verification)

### Technical Details

**Database Schema Overview**:

**1. ipo_financials table**:
```sql
CREATE TABLE IF NOT EXISTS ipo_financials (
  id SERIAL PRIMARY KEY,
  ipo_id INTEGER NOT NULL REFERENCES ipos(id) ON DELETE CASCADE,
  revenue DECIMAL(15, 2),
  profit DECIMAL(15, 2),
  net_worth DECIMAL(15, 2),
  eps DECIMAL(10, 2),
  pe_ratio DECIMAL(10, 2),
  roe DECIMAL(5, 2),
  fiscal_year VARCHAR(20),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(ipo_id, fiscal_year)
);
```

**2. subscriptions table**:
```sql
CREATE TABLE IF NOT EXISTS subscriptions (
  id SERIAL PRIMARY KEY,
  ipo_id INTEGER NOT NULL REFERENCES ipos(id) ON DELETE CASCADE,
  category VARCHAR(50),                    -- RII, NII, QIB, EMP
  subscription_times DECIMAL(10, 2),       -- e.g., 5.25x
  applications INTEGER,
  amount_bid DECIMAL(15, 2),
  recorded_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(ipo_id, category, recorded_at)
);
```

**3. gmp_tracking table**:
```sql
CREATE TABLE IF NOT EXISTS gmp_tracking (
  id SERIAL PRIMARY KEY,
  ipo_id INTEGER NOT NULL REFERENCES ipos(id) ON DELETE CASCADE,
  gmp_value DECIMAL(10, 2),
  gmp_percentage DECIMAL(5, 2),
  recorded_at TIMESTAMP DEFAULT NOW(),
  source VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(ipo_id, recorded_at)
);
```

**4. ipos table** (main table):
```sql
CREATE TABLE IF NOT EXISTS ipos (
  id SERIAL PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE NOT NULL,
  category VARCHAR(50),                    -- MAINBOARD, SME
  open_date DATE,
  close_date DATE,
  issue_price_min DECIMAL(10, 2),
  issue_price_max DECIMAL(10, 2),
  lot_size INTEGER,
  issue_size DECIMAL(15, 2),
  gmp DECIMAL(10, 2),                     -- Latest GMP value
  gmp_percentage DECIMAL(5, 2),           -- Latest GMP percentage
  gmp_updated_at TIMESTAMP,
  listing_date DATE,
  listing_price DECIMAL(10, 2),
  listing_gain_percentage DECIMAL(5, 2),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

**Data Verification Queries**:

```sql
-- 1. Check data population summary
SELECT
  'ipos' as table_name,
  COUNT(*) as record_count
FROM ipos
UNION ALL
SELECT
  'ipo_financials' as table_name,
  COUNT(*) as record_count
FROM ipo_financials
UNION ALL
SELECT
  'subscriptions' as table_name,
  COUNT(*) as record_count
FROM subscriptions
UNION ALL
SELECT
  'gmp_tracking' as table_name,
  COUNT(*) as record_count
FROM gmp_tracking;

-- 2. Check IPOs with complete data
SELECT
  i.id,
  i.name,
  i.slug,
  COUNT(DISTINCT f.id) as financial_records,
  COUNT(DISTINCT s.id) as subscription_records,
  COUNT(DISTINCT g.id) as gmp_records
FROM ipos i
LEFT JOIN ipo_financials f ON f.ipo_id = i.id
LEFT JOIN subscriptions s ON s.ipo_id = i.id
LEFT JOIN gmp_tracking g ON g.ipo_id = i.id
WHERE i.category IN ('MAINBOARD', 'SME')
GROUP BY i.id, i.name, i.slug
ORDER BY i.created_at DESC
LIMIT 20;

-- 3. Check for IPOs missing related data
SELECT
  i.id,
  i.name,
  i.slug,
  CASE WHEN EXISTS (SELECT 1 FROM ipo_financials f WHERE f.ipo_id = i.id)
    THEN 'YES' ELSE 'NO' END as has_financials,
  CASE WHEN EXISTS (SELECT 1 FROM subscriptions s WHERE s.ipo_id = i.id)
    THEN 'YES' ELSE 'NO' END as has_subscriptions,
  CASE WHEN EXISTS (SELECT 1 FROM gmp_tracking g WHERE g.ipo_id = i.id)
    THEN 'YES' ELSE 'NO' END as has_gmp
FROM ipos i
WHERE i.category IN ('MAINBOARD', 'SME')
  AND i.close_date >= NOW() - INTERVAL '30 days'
ORDER BY i.close_date DESC;

-- 4. Validate foreign key integrity
SELECT
  'Orphaned financials' as issue,
  COUNT(*) as count
FROM ipo_financials f
WHERE NOT EXISTS (SELECT 1 FROM ipos i WHERE i.id = f.ipo_id)
UNION ALL
SELECT
  'Orphaned subscriptions' as issue,
  COUNT(*) as count
FROM subscriptions s
WHERE NOT EXISTS (SELECT 1 FROM ipos i WHERE i.id = s.ipo_id)
UNION ALL
SELECT
  'Orphaned GMP records' as issue,
  COUNT(*) as count
FROM gmp_tracking g
WHERE NOT EXISTS (SELECT 1 FROM ipos i WHERE i.id = g.ipo_id);
```

2. **Data Completeness Check** (add to application):
```typescript
// lib/monitoring/data-completeness.ts
export async function checkDataCompleteness() {
  const result = await db.query(`
    SELECT
      COUNT(*) as total_ipos,
      COUNT(CASE WHEN EXISTS (
        SELECT 1 FROM ipo_financials f WHERE f.ipo_id = i.id
      ) THEN 1 END) as ipos_with_financials,
      COUNT(CASE WHEN EXISTS (
        SELECT 1 FROM subscriptions s WHERE s.ipo_id = i.id
      ) THEN 1 END) as ipos_with_subscriptions
    FROM ipos i
    WHERE i.close_date >= NOW() - INTERVAL '30 days'
  `);

  const { total_ipos, ipos_with_financials, ipos_with_subscriptions } = result.rows[0];
  const financialsRate = (ipos_with_financials / total_ipos) * 100;
  const subscriptionsRate = (ipos_with_subscriptions / total_ipos) * 100;

  if (financialsRate < 80 || subscriptionsRate < 80) {
    console.warn(`⚠️  Data completeness below threshold:
      Financials: ${financialsRate.toFixed(1)}%
      Subscriptions: ${subscriptionsRate.toFixed(1)}%
    `);
    // Send alert to monitoring system
  }
}
```
