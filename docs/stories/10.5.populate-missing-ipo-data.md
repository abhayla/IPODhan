### Technical Details

**Database Schema Overview** (⚠️ CORRECTED - Single Source of Truth: `packages/shared/src/db/schema.ts`):

**1. ipoFinancials table** (camelCase with quoted identifiers):
- Table name: `"ipoFinancials"`
- Primary Key: `id` (UUID)
- Foreign Key: `"ipoId"` → `ipos.id` (UUID, CASCADE DELETE)
- Key fields: `revenueFy1-3`, `profitFy1-3`, `peRatio`, `roePercentage`, `debtToEquity`, `pbRatio`, `rocePercentage`
- One-to-One relationship with `ipos` table

**2. financialData table** (alternate financial table):
- Table name: `"financialData"`
- Primary Key: `id` (UUID)
- Foreign Key: `"ipoId"` → `ipos.id` (UUID, CASCADE DELETE, UNIQUE)
- Key fields: `revenueFy2022-2024`, `profitFy2022-2024`, `netWorth`, `peRatio`, `eps`, `roe`, `debtToEquity`
- One-to-One relationship with `ipos` table
- NOTE: Duplicate of ipoFinancials - reconciliation needed

**3. subscriptions table** (time-series data):
- Table name: `"subscriptions"`
- Primary Key: `id` (UUID)
- Foreign Key: `"ipoId"` → `ipos.id` (UUID, CASCADE DELETE)
- Key fields: `qibSubscription`, `niiSubscription`, `retailSubscription`, `totalSubscription`
- Timestamp field: `timestamp` (for time-series tracking)
- Index: `idx_subscriptions_ipo_timestamp` on (`"ipoId"`, `timestamp`)

**4. gmpRecords table** (time-series GMP tracking):
- Table name: `"gmpRecords"`
- Primary Key: `id` (UUID)
- Foreign Key: `"ipoId"` → `ipos.id` (UUID, CASCADE DELETE)
- Key fields: `gmp` (integer, INR), `expectedListingPrice`, `subjectRate`, `kostakRate`, `source`
- Timestamp field: `timestamp`
- Index: `idx_gmp_records_ipo_timestamp` on (`"ipoId"`, `timestamp`)

**5. ipos table** (main table with embedded GMP/subscription fields):
- Table name: `"ipos"`
- Primary Key: `id` (UUID)
- Unique: `slug` (VARCHAR 255)
- Embedded subscription fields: `subscriptionRetail`, `subscriptionHni`, `subscriptionQib`, `subscriptionTotal`
- Embedded GMP fields: `gmpPrice`, `gmpPercentageHistorical`, `gmpUpdatedAtHistorical`
- Embedded listing fields: `listingPriceHistorical`, `listingGainPercentage`, `listingDateHistorical`
- Current price tracking: `currentPrice`, `currentGainPercentage`, `currentPriceUpdatedAt`
- Metadata: `historicalDataSource`, `historicalDataScrapedAt`

**⚠️ IMPORTANT ARCHITECTURE NOTES**:
1. **Duplicate Tables**: Both `ipoFinancials` and `financialData` exist for financial data
2. **GMP Storage**: GMP data stored in TWO places:
   - Time-series: `gmpRecords` table (historical tracking)
   - Latest value: `ipos` table columns (embedded for performance)
3. **Subscription Storage**: Subscription data stored in TWO places:
   - Time-series: `subscriptions` table (live tracking during IPO)
   - Final value: `ipos` table columns (embedded from historical scraper)
4. **Historical Scraper Behavior**: Chittorgarh scraper populates `ipos` table directly, NOT separate tables

```typescript
// lib/monitoring/data-completeness.ts
export async function checkDataCompleteness() {
  const result = await db.query(`
    SELECT
      COUNT(*) as total_ipos,
      COUNT(CASE WHEN EXISTS (
        SELECT 1 FROM ipo_financials f WHERE f.ipo_id = i.id
      ) THEN 1 END) as ipos_with_financials,
      COUNT(CASE WHEN EXISTS (
        SELECT 1 FROM subscriptions s WHERE s.ipo_id = i.id
      ) THEN 1 END) as ipos_with_subscriptions
    FROM ipos i
    WHERE i.close_date >= NOW() - INTERVAL '30 days'
  `);

  const { total_ipos, ipos_with_financials, ipos_with_subscriptions } = result.rows[0];
  const financialsRate = (ipos_with_financials / total_ipos) * 100;
  const subscriptionsRate = (ipos_with_subscriptions / total_ipos) * 100;

  if (financialsRate < 80 || subscriptionsRate < 80) {
    console.warn(`⚠️  Data completeness below threshold:
      Financials: ${financialsRate.toFixed(1)}%
      Subscriptions: ${subscriptionsRate.toFixed(1)}%
    `);
    // Send alert to monitoring system
  }
}
```
