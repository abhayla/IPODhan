## Story
**As a** user who applied for an IPO,
**I want** an allotment status checker that redirects me to the registrar website,
**so that** I can quickly check if I received IPO shares.

### PAN Validation

[Source: epic-4-sharded.md#acceptance-criteria]

**PAN Format:** AAAAA9999A
- 5 uppercase letters
- 4 digits
- 1 uppercase letter

**Validation Regex:**
```typescript
const panRegex = /^[A-Z]{5}[0-9]{4}[A-Z]{1}$/;
```

**Validation Logic:**
```typescript
function validatePan(pan: string): boolean {
  const upperPan = pan.toUpperCase();
  if (upperPan.length !== 10) return false;
  return panRegex.test(upperPan);
}
```

**Input Constraints:**
- Auto-convert to uppercase (user can type lowercase)
- Max length: 10 characters
- Show error message for invalid format
- Disable submit button until valid PAN entered

### Repository Pattern

[Source: architecture/components.md#repository-layer]

**Registrar Repository Interface:**
```typescript
// web/lib/repositories/registrar.repository.ts
import { db } from '@/lib/db';
import { registrars } from '@/lib/db/schema/registrar';
import { eq } from 'drizzle-orm';
import { redis } from '@/lib/redis';

export class RegistrarRepository {
  async findById(id: string): Promise<Registrar | null> {
    // Check Redis cache first
    const cacheKey = `registrar:${id}`;
    const cached = await redis.get(cacheKey);
    if (cached) return JSON.parse(cached);

    // Query database
    const registrar = await db.select()
      .from(registrars)
      .where(eq(registrars.id, id))
      .limit(1);

    if (registrar[0]) {
      // Cache for 24 hours
      await redis.setex(cacheKey, 86400, JSON.stringify(registrar[0]));
    }

    return registrar[0] || null;
  }

  async findByName(name: string): Promise<Registrar | null> {
    const registrar = await db.select()
      .from(registrars)
      .where(eq(registrars.name, name))
      .limit(1);

    return registrar[0] || null;
  }

  async findAll(activeOnly: boolean = true): Promise<Registrar[]> {
    const query = db.select().from(registrars);

    if (activeOnly) {
      query.where(eq(registrars.active, true));
    }

    return await query;
  }
}

export const registrarRepository = new RegistrarRepository();
```
