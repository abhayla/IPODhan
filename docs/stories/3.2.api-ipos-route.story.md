### API Specification
**Source:** [docs/architecture/api-specification.md]

**Endpoint:** `GET /api/ipos`

**Query Parameters:**
- `status` (optional): IPO status filter (UPCOMING | OPEN | CLOSED | LISTED) - supports array
- `category` (optional): IPO category filter (MAINBOARD | SME | RIGHTS | NCD) - supports array
- `sector` (optional): Sector name filter (string)
- `page` (optional): Page number (default: 1)
- `limit` (optional): Results per page (default: 20, max: 100)
- `sortBy` (optional): Sort field (default: createdAt)

### Error Handling Strategy
**Source:** [docs/architecture/error-handling-strategy.md]

**Error Response Format:**
```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "No IPOs found matching filters",
    "details": { "filters": {...} },
    "timestamp": "2025-01-05T10:30:00.000Z",
    "requestId": "req_abc123"
  }
}
```

**Error Flow:**
1. Validate query parameters with Zod
2. If validation fails → 400 Bad Request with validation errors
3. Call IPORepository.findAll()
4. If DatabaseError → 500 Internal Server Error, log to Sentry
5. If no results → Return empty array with pagination (NOT an error)
6. All errors logged with Pino logger including request ID

**HTTP Status Codes:**
- `200 OK` - Success (even if empty results)
- `400 Bad Request` - Invalid query parameters
- `500 Internal Server Error` - Database/Redis errors

**Example Error Handler:**
```typescript
try {
  const result = await repo.findAll(filters);
  return Response.json(result);
} catch (error) {
  logger.error({ error, requestId }, 'Failed to fetch IPOs');

  if (error instanceof DatabaseError) {
    Sentry.captureException(error);
    return Response.json(
      { error: { code: 'DATABASE_ERROR', message: 'Failed to fetch IPOs', requestId } },
      { status: 500 }
    );
  }

  throw error;
}
```

### Coding Standards
**Source:** [docs/architecture/coding-standards.md]

**Critical Rules for API Routes:**
1. **Never query database directly** - Always use Repository layer
2. **Input validation** - Validate all query params with Zod schemas
3. **Error handling** - Use try-catch with proper error responses
4. **Logging** - Log all requests with request ID and execution time
5. **Type safety** - Use TypeScript types from Drizzle schema
6. **Response format** - Use standard JSON structure with pagination

**Naming Conventions:**
- API route files: `route.ts` (Next.js App Router convention)
- Function exports: `GET`, `POST`, `PUT`, `DELETE` (HTTP method names)
- Query params: camelCase (e.g., `sortBy`, `sortOrder`)
- Response fields: camelCase (e.g., `hasMore`, `createdAt`)

**Example Route Structure:**
```typescript
import { NextRequest } from 'next/server';
import { z } from 'zod';

// Define query schema
const querySchema = z.object({
  status: z.enum(['UPCOMING', 'OPEN', 'CLOSED', 'LISTED']).optional(),
  page: z.coerce.number().min(1).default(1),
  limit: z.coerce.number().min(1).max(100).default(20),
});

export async function GET(request: NextRequest) {
  const requestId = `req_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
  const startTime = Date.now();

  try {
    // Parse and validate query params
    const { searchParams } = new URL(request.url);
    const params = querySchema.parse(Object.fromEntries(searchParams));

    // Fetch data using repository
    const repo = new IPORepository(db, redis);
    const result = await repo.findAll(params);

    // Log success
    logger.info({ requestId, duration: Date.now() - startTime }, 'IPO list fetched');

    // Return response with cache headers
    return Response.json(result, {
      headers: { 'Cache-Control': 'public, max-age=300' }
    });
  } catch (error) {
    logger.error({ error, requestId }, 'Failed to fetch IPOs');

    // Handle errors appropriately
    if (error instanceof z.ZodError) {
      return Response.json(
        { error: { code: 'VALIDATION_ERROR', message: 'Invalid query parameters', details: error.errors, requestId } },
        { status: 400 }
      );
    }

    return Response.json(
      { error: { code: 'INTERNAL_ERROR', message: 'Failed to fetch IPOs', requestId } },
      { status: 500 }
    );
  }
}
```

**Pagination Parameters:**
