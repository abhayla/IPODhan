## Template Usage Guide

### Issue Types

- **Bug**: Something is broken or not working as expected
- **Task**: Specific work item that needs to be completed
- **Improvement**: Enhancement to existing functionality
- **Investigation**: Research or analysis needed
- **Documentation**: Documentation updates or creation

### Priority Guidelines

- **P0**: Blocking production, critical functionality broken
- **P1**: Important functionality affected, needs quick resolution
- **P2**: Normal priority, fix in current sprint
- **P3**: Low priority, fix when time allows

### Effort Estimation

- Small: < 2 hours
- Medium: 2-4 hours
- Large: 4-8 hours
- X-Large: > 8 hours (consider breaking down)
