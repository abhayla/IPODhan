## 🔍 Root Cause Analysis

### Why Backend API Doesn't Exist

**Review of Stories:**

**Story 1.2 (Data Pipeline):**
- **Purpose:** Scrape IPO data and populate database
- **Deliverable:** Python CLI tool with schedulers
- **Output:** PostgreSQL database with IPO data
- **Does NOT include:** REST API server

**Story 1.3 (Score Engine):**
- **Purpose:** Calculate IPO scores
- **Deliverable:** FastAPI server on port 8001
- **Endpoints:** `/api/scores/:id`, `/api/scores/:id/history`
- **Does NOT include:** IPO data serving (only scores)

**Story 1.4 (Web Platform MVP):**
- **Purpose:** Frontend for IPO research
- **Deliverable:** Next.js application
- **Assumes:** Backend API on port 8000 exists
- **Reality:** Backend API was not in scope, not implemented

### Architecture Planning Gap

**The issue:** Story 1.4 was developed with the assumption that a backend API would exist, but no story explicitly created it.

**Likely Resolution:** Story 1.5 or dedicated backend API story needed.
