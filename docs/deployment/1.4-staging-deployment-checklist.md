## Staging Environment Setup

### Option A: Vercel Deployment (Recommended)

#### 1. Install Vercel CLI (if not installed)
```bash
npm install -g vercel
```

#### 2. Login to Vercel
```bash
vercel login
```

#### 3. Deploy to Staging
```bash
cd ipodhan-web

# Deploy to staging (preview environment)
vercel --prod=false

# Or explicitly specify staging
vercel deploy --target=preview
```

#### 4. Configure Environment Variables in Vercel Dashboard
- Navigate to: https://vercel.com/dashboard → Project → Settings → Environment Variables
- Add the following for **Preview** environment:

```
NEXT_PUBLIC_API_URL=https://api-staging.ipodhan.com
NEXT_PUBLIC_SCORE_API_URL=https://score-api-staging.ipodhan.com
NEXT_PUBLIC_ENV=staging
NEXT_PUBLIC_GA_ID=(staging GA ID)
```

#### 5. Verify Deployment
- Check deployment URL (e.g., `ipodhan-web-xyz.vercel.app`)
- Verify environment variables loaded
- Check build logs for errors

---

### Option B: Manual Build and Deploy

#### 1. Build the Application
```bash
cd ipodhan-web

# Install dependencies
npm install

# Run build
npm run build
```

#### 2. Test Production Build Locally
```bash
# Start production server
npm run start

# Access at http://localhost:3000
```

#### 3. Deploy to Staging Server
```bash
# Example: Deploy to staging server via SSH
scp -r .next/* user@staging-server:/var/www/ipodhan-staging/
scp -r public/* user@staging-server:/var/www/ipodhan-staging/public/
scp package.json user@staging-server:/var/www/ipodhan-staging/

# SSH into staging server
ssh user@staging-server

# Install dependencies
cd /var/www/ipodhan-staging
npm install --production

# Restart Next.js service
pm2 restart ipodhan-web
```

```bash
# Rollback to previous deployment

```

#### Manual Rollback
```bash
# SSH into staging server
ssh user@staging-server

# Restore previous version
cd /var/www/ipodhan-staging
git checkout <previous-commit-hash>
npm run build
pm2 restart ipodhan-web
```

### Rollback Triggers
- Error rate > 5% for 5 minutes
- API failures > 10% for 5 minutes
- Critical security vulnerability discovered
