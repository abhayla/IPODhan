## Prerequisites

### Server Requirements
- **OS:** Windows Server 2022
- **RAM:** Minimum 4GB (8GB recommended)
- **Storage:** 20GB free space
- **Network:** Static IP address or domain name
- **Ports:** 80 (HTTP), 443 (HTTPS), 3000 (Next.js default)

### Software Required
- [x] Node.js 18+ LTS
- [x] Git for Windows
- [x] IIS (Internet Information Services) - Optional, for reverse proxy
- [x] PM2 (for process management)
- [ ] SSL Certificate (Let's Encrypt or commercial)

## Part 1: Server Setup

### 1.1 Install Node.js on Windows Server

#### Download Node.js
1. Open PowerShell as Administrator
2. Download Node.js 18 LTS:

```powershell
# Download Node.js installer
$nodeUrl = "https://nodejs.org/dist/v18.19.0/node-v18.19.0-x64.msi"
$installerPath = "$env:TEMP\nodejs-installer.msi"
Invoke-WebRequest -Uri $nodeUrl -OutFile $installerPath

# Run installer
Start-Process msiexec.exe -ArgumentList "/i $installerPath /quiet /norestart" -Wait

# Refresh environment variables
$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
```

#### Verify Installation
```powershell
node --version  # Should show v18.x.x
npm --version   # Should show 9.x.x or higher
```

### 1.2 Install Git for Windows

```powershell
# Download Git installer
$gitUrl = "https://github.com/git-for-windows/git/releases/download/v2.42.0.windows.2/Git-2.42.0.2-64-bit.exe"
$gitInstaller = "$env:TEMP\git-installer.exe"
Invoke-WebRequest -Uri $gitUrl -OutFile $gitInstaller

# Install Git
Start-Process $gitInstaller -ArgumentList "/VERYSILENT /NORESTART" -Wait
```

### 1.3 Install PM2 (Process Manager)

```powershell
# Install PM2 globally
npm install -g pm2

# Install PM2 Windows service (keeps PM2 running after reboot)
npm install -g pm2-windows-service

# Setup PM2 service
pm2-service-install -n PM2
```

### 1.4 Configure Windows Firewall

```powershell
# Allow Node.js through firewall
New-NetFirewallRule -DisplayName "Node.js HTTP" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow

# Allow HTTPS (443) if using SSL
New-NetFirewallRule -DisplayName "HTTPS" -Direction Inbound -LocalPort 443 -Protocol TCP -Action Allow

# Allow HTTP (80) for redirect
New-NetFirewallRule -DisplayName "HTTP" -Direction Inbound -LocalPort 80 -Protocol TCP -Action Allow
```

## Part 4: IIS Reverse Proxy (Optional but Recommended)

### 4.1 Why Use IIS as Reverse Proxy?
- Run Next.js on port 3000, expose on port 80/443
- Better security (no direct exposure of Node.js)
- SSL/TLS termination
- URL rewriting
- Load balancing (for future scaling)

### 4.2 Install IIS

```powershell
# Install IIS with required features
Install-WindowsFeature -name Web-Server -IncludeManagementTools

# Install URL Rewrite module (required for reverse proxy)
# Download from: https://www.iis.net/downloads/microsoft/url-rewrite
# Or use Chocolatey:
# choco install urlrewrite -y

# Install Application Request Routing (ARR)
# Download from: https://www.iis.net/downloads/microsoft/application-request-routing
# Or use Chocolatey:
# choco install iis-arr -y
```

### 4.3 Configure IIS Reverse Proxy

#### Enable Proxy in ARR
1. Open **IIS Manager**
2. Click on server name (top level)
3. Double-click **Application Request Routing Cache**
4. Click **Server Proxy Settings** (right panel)
5. Check **Enable proxy**
6. Click **Apply**

#### Create Website in IIS
```powershell
# Import IIS module
Import-Module WebAdministration

# Create application pool
New-WebAppPool -Name "IPODhanWebPool"

# Create website
New-Website -Name "IPODhan-Staging" `
    -Port 80 `
    -PhysicalPath "C:\inetpub\ipodhan-web\public" `
    -ApplicationPool "IPODhanWebPool"
```

#### Configure URL Rewrite Rules

1. Open **IIS Manager**
2. Select **IPODhan-Staging** website
3. Double-click **URL Rewrite**
4. Click **Add Rule(s)** → **Reverse Proxy**
5. Enter: `localhost:3000`
6. Click **OK**

**Or create web.config manually:**

```powershell
cd C:\inetpub\ipodhan-web

@"
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <system.webServer>
        <rewrite>
            <rules>
                <rule name="ReverseProxyInboundRule" stopProcessing="true">
                    <match url="(.*)" />
                    <action type="Rewrite" url="http://localhost:3000/{R:1}" />
                    <serverVariables>
                        <set name="HTTP_X_FORWARDED_PROTO" value="http" />
                        <set name="HTTP_X_ORIGINAL_HOST" value="{HTTP_HOST}" />
                    </serverVariables>
                </rule>
            </rules>
        </rewrite>
        <httpProtocol>
            <customHeaders>
                <add name="X-Frame-Options" value="SAMEORIGIN" />
                <add name="X-Content-Type-Options" value="nosniff" />
            </customHeaders>
        </httpProtocol>
    </system.webServer>
</configuration>
"@ | Out-File -FilePath web.config -Encoding UTF8
```

### 4.4 Bind Domain Name (if available)

```powershell
# In IIS Manager:
# 1. Select IPODhan-Staging website
# 2. Click "Bindings" (right panel)
# 3. Click "Add"
# 4. Type: http
# 5. Port: 80
# 6. Host name: staging.ipodhan.com
# 7. Click OK

# Or via PowerShell:
New-WebBinding -Name "IPODhan-Staging" -Protocol "http" -Port 80 -HostHeader "staging.ipodhan.com"
```

## Part 5: SSL/HTTPS Setup (Production Requirement)

### 5.1 Option A: Self-Signed Certificate (Testing Only)

```powershell
# Create self-signed certificate
$cert = New-SelfSignedCertificate `
    -DnsName "staging.ipodhan.com" `
    -CertStoreLocation "cert:\LocalMachine\My"

# Bind to IIS website
New-WebBinding -Name "IPODhan-Staging" -Protocol "https" -Port 443
$binding = Get-WebBinding -Name "IPODhan-Staging" -Protocol "https"
$binding.AddSslCertificate($cert.Thumbprint, "my")
```

### 5.2 Option B: Let's Encrypt (Free, Production-Ready)

#### Install Win-ACME (Let's Encrypt Client for Windows)
```powershell
# Download Win-ACME
$wacmeUrl = "https://github.com/win-acme/win-acme/releases/download/v2.2.6/win-acme.v2.2.6.1533.x64.pluggable.zip"
$wacmeZip = "C:\Tools\win-acme.zip"
New-Item -ItemType Directory -Path "C:\Tools" -Force
Invoke-WebRequest -Uri $wacmeUrl -OutFile $wacmeZip

# Extract
Expand-Archive -Path $wacmeZip -DestinationPath "C:\Tools\win-acme"

# Run Win-ACME
cd C:\Tools\win-acme
.\wacs.exe

# Follow prompts:
# 1. Choose "M" for create certificate with advanced options
# 2. Choose "2" for single binding of an IIS site
# 3. Select IPODhan-Staging website
# 4. Enter email address
# 5. Accept terms
# Certificate will auto-renew every 60 days
```

### 5.3 Option C: Commercial SSL Certificate

1. Purchase SSL from provider (Namecheap, GoDaddy, etc.)
2. Generate CSR in IIS:
   - Open IIS Manager → Server Certificates → Create Certificate Request
3. Submit CSR to SSL provider
4. Download certificate files
5. Complete Certificate Request in IIS
6. Bind certificate to website

## Part 7: Monitoring & Maintenance

### 7.1 Setup Scheduled Task for Health Check

```powershell
# Create health check script
$healthCheckScript = @"
`$url = "http://localhost:3000"
try {
    `$response = Invoke-WebRequest -Uri `$url -UseBasicParsing -TimeoutSec 10
    if (`$response.StatusCode -ne 200) {
        # Restart PM2 app
        pm2 restart ipodhan-web-staging
        Write-EventLog -LogName Application -Source "IPODhan" -EventID 1001 -EntryType Warning -Message "IPODhan web app restarted due to health check failure"
    }
} catch {
    pm2 restart ipodhan-web-staging
    Write-EventLog -LogName Application -Source "IPODhan" -EventID 1001 -EntryType Warning -Message "IPODhan web app restarted due to health check failure: `$_"
}
"@

$healthCheckScript | Out-File -FilePath "C:\Scripts\ipodhan-health-check.ps1" -Encoding UTF8

# Create scheduled task (runs every 5 minutes)
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-File C:\Scripts\ipodhan-health-check.ps1"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 5) -RepetitionDuration ([TimeSpan]::MaxValue)
$principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -LogonType ServiceAccount
Register-ScheduledTask -TaskName "IPODhan Health Check" -Action $action -Trigger $trigger -Principal $principal
```

### 7.2 Log Rotation

```powershell
# PM2 log rotation
pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 7
```

### 7.3 Backup Script

```powershell
# Create backup script
$backupScript = @"
`$timestamp = Get-Date -Format "yyyyMMdd-HHmmss"
`$backupDir = "C:\Backups\ipodhan-web"
`$appDir = "C:\inetpub\ipodhan-web"

New-Item -ItemType Directory -Path `$backupDir -Force

# Backup application files
Compress-Archive -Path `$appDir\* -DestinationPath "`$backupDir\ipodhan-web-`$timestamp.zip"

# Delete backups older than 30 days
Get-ChildItem `$backupDir -Filter *.zip | Where-Object {`$_.LastWriteTime -lt (Get-Date).AddDays(-30)} | Remove-Item
"@

$backupScript | Out-File -FilePath "C:\Scripts\ipodhan-backup.ps1" -Encoding UTF8

# Schedule daily backup at 2 AM
$action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-File C:\Scripts\ipodhan-backup.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At 2am
Register-ScheduledTask -TaskName "IPODhan Daily Backup" -Action $action -Trigger $trigger -Principal $principal
```

## Part 8: Troubleshooting

### 8.1 Application Won't Start

```powershell
# Check Node.js version
node --version  # Should be 18+

# Check if port 3000 is already in use
netstat -ano | findstr :3000

# Kill process using port 3000
taskkill /PID <PID> /F

# Check PM2 status
pm2 status
pm2 logs ipodhan-web-staging --err

# Try starting manually
cd C:\inetpub\ipodhan-web
npm run start
```

### 8.2 IIS Not Proxying Correctly

```powershell
# Verify URL Rewrite is installed
Get-WebConfigurationProperty -PSPath 'MACHINE/WEBROOT/APPHOST' -Filter "system.webServer/rewrite/rules" -Name "."

# Check IIS website status
Get-Website -Name "IPODhan-Staging"

# Restart IIS
iisreset

# Check IIS logs
Get-Content "C:\inetpub\logs\LogFiles\W3SVC1\*.log" -Tail 50
```

### 8.3 High Memory Usage

```powershell
# Check Node.js memory
Get-Process node | Select-Object ProcessName, @{Name="Memory(MB)";Expression={$_.WorkingSet64 / 1MB}}

# Restart application
pm2 restart ipodhan-web-staging

# Increase Node.js memory limit (if needed)
pm2 delete ipodhan-web-staging
pm2 start npm --name "ipodhan-web-staging" --node-args="--max-old-space-size=2048" -- start
```

### 8.4 Port Already in Use

```powershell
# Find process using port 3000
netstat -ano | findstr :3000

# Kill the process
taskkill /PID <PID> /F

# Or change Next.js port
# Edit package.json: "start": "next start -p 3001"
```
