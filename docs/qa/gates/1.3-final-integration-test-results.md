### 2. Materialized View Refresh Strategy

**Issue:** `current_ipo_scores` materialized view not auto-refreshing after INSERT operations
**Impact:** Tests failing because newly inserted scores not visible in view queries

**Fix Applied:**
- Added explicit `repository.refresh_materialized_view()` calls after score inserts
- Updated 6 test methods to refresh view before querying latest scores
- Modified manual override test to validate against raw `score_history` instead of view

**Files Modified:**
- `tests/integration/test_score_repository.py` (2 methods)
- `tests/integration/test_score_api.py` (4 methods)

**Code Pattern:**
```python
# Save score
repository.save_score_history(score)

# Refresh materialized view (CRITICAL for tests)
repository.refresh_materialized_view()

# Now query will return latest data
latest = repository.get_latest_score(ipo_id)
```

**Result:** All materialized view-dependent tests now pass ✅
