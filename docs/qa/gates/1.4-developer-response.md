### 🟢 RESOLVED: TEST-001 (Code Coverage Not Measured) - Priority: REQUIRED

#### 2. Fixed Integration Test Failures
**Problem:** Integration tests failing due to axios mocking issues
- Root cause: `apiClient` and `scoreApiClient` created at module load time
- Mocking `axios.create` after module load had no effect

**Solution:** Rewrote mocking strategy in `tests/integration/api/ipo.service.test.ts`
```typescript
// BEFORE (failed):
vi.mock('axios');
mockedAxios.create.mockReturnValue({...})

// AFTER (fixed):
vi.mock('@/lib/api/client', () => ({
  apiClient: { get: vi.fn() },
  scoreApiClient: { get: vi.fn() },
  handleApiError: vi.fn((error) => error),
}));
```
- Added missing validation to `getIPOScore()` function

### Coverage Gap Discussion (13.86% vs 70% Target)

**Reality Check:**

The 13.86% overall coverage reflects the nature of an MVP web platform:
- **40+ files created** (pages, components, layouts)
- **7 test files** (focused on business logic)
- **1,234 total lines** (most are Next.js routing/scaffolding)

**What's Well-Covered:**
- ✅ Validation logic: **97.59%** (critical security boundary)
- ✅ State management: **64%** (core business logic)
- ✅ Key components: **79-100%** (Hero, Pagination)
- ✅ API error handling: Validated in 9 integration tests

**What's Not Covered:**
- Next.js routing pages (`app/*` directory) - 40+ files
- Layout components (mostly JSX markup)
- Utility functions in use but not tested
- Component variants/edge cases

**Trade-off Analysis:**

To reach 70% coverage would require:
1. **Page-level unit tests:** Extensive mocking of Next.js routing, metadata, loading states
2. **Shallow component tests:** Testing JSX rendering without user interaction
3. **Time investment:** Estimated 8-12 hours for 50+ additional tests

**MVP Pragmatism:**
- Business logic (validation, stores, API) has strong coverage
- E2E tests exist for user flows (separate Playwright suite)
- Security boundaries are validated (SEC-001 resolved at 97.59%)
- Additional page tests add diminishing value for MVP

**Recommendation:**
Accept 13.86% coverage with acknowledgment that:
- Critical paths are tested (validation, state management)
- E2E tests cover integration scenarios
- Full page coverage should come in Story 1.5+ with feature maturity
