## Known Issues & Recommendations

### 🔴 HIGH Priority

**None** - All critical functionality is working

### 🟡 MEDIUM Priority

1. **Materialized View Refresh Strategy**
   - **Issue:** `current_ipo_scores` view not updating immediately after INSERT
   - **Impact:** `get_latest_score()` returns None for newly inserted scores
   - **Recommendation:**
     - Option 1: Add manual `REFRESH MATERIALIZED VIEW` call after score insert
     - Option 2: Use regular view instead of materialized view (performance tradeoff)
     - Option 3: Update tests to call `repository.refresh_materialized_view()` before queries

2. **HTTP Status Code Consistency**
   - **Issue:** API returns 401 (Unauthorized) but tests expect 403 (Forbidden)
   - **Impact:** 2 API tests failing
   - **Recommendation:** Standardize on 401 for missing/invalid API keys, update tests

### 🟢 LOW Priority

1. **Test Assertion Logic**
   - **Issue:** `test_ab_testing_correlation_calculation` has overly permissive assertion
   - **Recommendation:** Simplify to `assert isinstance(correlation, dict)`

2. **Deprecation Warnings (85 warnings)**
   - **Issue:** `datetime.utcnow()` deprecated in Python 3.13
   - **Files:** `ab_testing.py`, `score_repository.py`, `api/main.py`
   - **Recommendation:** Replace with `datetime.now(timezone.utc)`

3. **FastAPI Lifecycle Events**
   - **Issue:** `@app.on_event("shutdown")` deprecated
   - **Recommendation:** Migrate to lifespan event handlers
