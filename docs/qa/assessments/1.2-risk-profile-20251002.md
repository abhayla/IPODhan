## High-Risk Items (Score 6)

### 1. [TECH-001]: Web Scraper Fragility

**Score: 6 (High)**
**Probability**: Medium (2) - NSE/BSE websites change periodically
**Impact**: High (3) - Pipeline breaks if selectors fail

**Description:**
Web scrapers rely on HTML structure from NSE/BSE websites. Website changes will break data ingestion.

**Affected Components:**
- `scrapers/nse_scraper.py`
- `scrapers/bse_scraper.py`

**Mitigation Strategy:**
-  Multi-source redundancy (NSE + BSE)
-  Retry mechanism (3 attempts, exponential backoff)
-  Health monitoring with alerts (>3 failures)
-  Anti-bot detection bypasses implemented
-   Recommend automated visual regression testing
-   Fallback to manual API (Task 7 pending)

**Residual Risk:** MEDIUM - Manual intervention needed if both sources fail
