## Continuous Integration Integration

### Test Execution in CI/CD

**Pre-Commit Hooks:**
```bash
# Run before commit
- Linting (ESLint, Prettier, Black)
- Unit tests (fast only, <30s)
```

**Pull Request Pipeline:**
```bash
# Run on PR creation/update
- All unit tests
- Integration tests (local Docker only)
- Code coverage check (>70%)
```

**Main Branch Pipeline:**
```bash
# Run on merge to main
- All unit tests
- All integration tests
- E2E smoke tests (critical paths only)
- Deploy to staging
```

**Release Pipeline:**
```bash
# Run before production deployment
- All tests (unit + integration + E2E)
- Security scans
- Performance tests
- Deploy to production
```

## Test Maintenance Strategy

### Test Review Triggers
- After architecture changes
- When new services added
- After production incidents
- Monthly test effectiveness review

### Test Decommissioning Criteria
- Feature removed from product
- Test consistently passes for 6 months (consider moving to P2)
- Test duplicates coverage of another test

### Test Evolution
- Update tests when acceptance criteria change
- Add tests for newly discovered edge cases
- Refactor tests when implementation patterns change
